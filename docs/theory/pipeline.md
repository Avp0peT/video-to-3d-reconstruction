# 数学原理说明：从图像到识别

本文说明项目的数学主线，以及**每一步为什么成立**。
它是 README 第 21 节「为什么？」面板与第 22 节演示故事线的文字版本。

面向读者：不要求读过教材，只要求会线性代数。

---

## 0. 一句话概括

> 绝对坐标不是视觉对象的可靠描述；但「相对于图像自身三个点的坐标」是——
> 它对一切可逆仿射变换保持不变，因此可以充当图像的**编码**。

---

## 1. 图像 = 有限点集

$$X=\{x_1,\ldots,x_n\}\subset\mathbb R^2,\qquad n\ge 1 .$$

这是教材的出发点。它带来一个立即可验证的推论：

**图像的"描述"不能是坐标清单**，因为同一个视觉对象平移之后坐标清单全变了。

- $X$ 与 $X+t$ 的坐标逐位不同；
- 但任何观察者都会说它们是同一个东西。

于是问题变成：**什么样的量既是可计算的，又对这类变化免疫？**

---

## 2. 变换的层级

$$\text{平移}\subset\text{等距}\subset\text{相似}\subset\text{仿射}$$

$$\text{translation}:\ x'=x+t$$
$$\text{isometry}:\ x'=Rx+t,\quad R^{T}R=I$$
$$\text{similarity}:\ x'=sRx+t,\quad s>0$$
$$\text{affine}:\ x'=Ax+t,\quad \det A\neq0$$

越往右，被破坏的性质越多：

| 性质 | 平移 | 等距 | 相似 | 仿射 |
|---|---|---|---|---|
| 绝对坐标 | × | × | × | × |
| 距离 | ✓ | ✓ | × | × |
| 角度 | ✓ | ✓ | ✓ | × |
| 长度比例 | ✓ | ✓ | ✓ | × |
| 共线性 | ✓ | ✓ | ✓ | ✓ |
| 平行性 | ✓ | ✓ | ✓ | ✓ |

**关键观察**：如果我们的目标是"认出同一个对象"，那么越靠下的性质越有用。
我们需要的是在**最大的变换族**下都保持的量——仿射不变量。

这张表在本项目中不是文字，而是被**测量**的：
`experiments/exp_invariant_table.py` 对每一格给出实测值与见证
（见 [`experiments/M6-invariant-table.md`](experiments/M6-invariant-table.md)）。

## 3. 内部仿射坐标

取三点 $A,B,C$ 且不共线。则任意 $P$ 有唯一分解

$$P-A=\alpha(B-A)+\beta(C-A).$$

解之：

$$\begin{pmatrix}\alpha\\\beta\end{pmatrix}=[\,B-A\quad C-A\,]^{-1}(P-A).$$

### 为什么它在仿射变换下不变

设 $T(x)=Mx+t$，$M$ 可逆。由 $P-A=\alpha u+\beta v$（$u=B-A,\ v=C-A$）得

$$TP-TA=M(P-A)=\alpha(Mu)+\beta(Mv).$$

而 $Mu=TB-TA$、$Mv=TC-TA$。由于 $M$ 可逆，$Mu,Mv$ 仍线性无关，
所以 $(TA,TB,TC)$ 是合法标架；由分解的**唯一性**，$(\alpha',\beta')=(\alpha,\beta)$。∎

### 为什么必须三点不共线

若 $B-A$ 与 $C-A$ 线性相关，二者只张成一条直线。
$(P-A)$ 中垂直于该直线的分量无法表示，分解不存在或不唯一。
形式化地：$\det[B-A,\ C-A]\ne0$。

### 为什么判据必须无量纲

$\det[B-A,\ C-A]$ 是**面积**。同一个"很扁的三角形"放大 $10^6$ 倍后，
行列式变成 $10^{12}$ 倍。任何固定的行列式阈值都会在大图像上判"不共线"、
在小图像上判"共线"。

正确做法是用无量纲量。本项目用**平坦度**

$$\mathrm{flatness}=\frac{2\,\mathrm{Area}}{\max(\text{边长})^2}
=\frac{h_{\min}}{\max(\text{边长})}$$

它仍是置换不变的（对三个点对称）。这一点很重要，因为
$|\sin(\angle BAC)|$ **依赖哪个点叫 $A$**，因此不能用来定义"三点共线"这个关系。
（该问题由 Hypothesis 在 $10^3$ 量级随机样本中发现，反例见
[`specs/affine_coordinates.md`](specs/affine_coordinates.md) §2.2。）

## 4. 从"不变量"到"编码"

单个点的 $(\alpha,\beta)$ 已经是仿射不变量。要把整幅图像编码，
最直接的做法是选一个标架 $(A,B,C)$，把所有点写在这个标架下：

$$\text{frame code}=(\alpha_1,\beta_1,\ldots,\alpha_n,\beta_n).$$

### 但标架的选择不是唯一的

$n$ 个点里有 $\binom{n}{3}$ 个候选标架。不同标架给出不同的 code，
而它们描述的是同一幅图像。所以必须**消除这个自由度**：

1. 枚举所有合法标架，得到 $\binom{n}{3}$ 个 frame code；
2. 在 code 内部对点排序（消除点编号的影响）；
3. 量化浮点（消除最后几位的噪声）；
4. 对所有 frame code 排序，取规范代表（消除标架选择的影响）。

得到的规范形式只依赖图像**作为集合**的内容——这正是我们需要的不变量。

### 点编号为什么必须消除

同一幅图像，点的书写顺序不同，$(\alpha_i,\beta_i)$ 的**列表顺序**就不同。
若直接用列表当 code，那么"同一幅图像"会得到 $n!$ 个不同 code。
先排序再量化，就把"集合"语义真正落实到了编码上。

### 哈希的位置

对规范形式算 SHA-256 可以做快速索引。但必须说清：

> **哈希不是数学图像代码本身，只能是代码的计算机索引。**

因为哈希**不连续**：坐标上一个 $10^{-16}$ 的扰动会让哈希完全改变，
而数学上这两个图像是"几乎相同"的。把哈希当不变量会得到一个
对噪声毫无容忍度的识别器，且无法回答"差多少"。

## 5. 等价判定

问题：给定 $X,Y$，是否存在可逆仿射 $T$ 使 $T(X)=Y$？

### 方法 A（编码比较）

计算两者的规范 code，比较是否相等。优点是一次编码可复用于多次比较。

### 方法 B（控制点求解）

枚举三对非共线对应点，解出 $(A,t)$，再验证其余点是否吻合。

**两种方法不是同一件事的两种实现**：
方法 A 依赖 Phase 3 的规范形式，方法 B 更直接但组合爆炸。
README 第 8 节要求比较它们的正确率、运行时间与随点数的增长关系，
正是因为二者的复杂度结构完全不同。

### 必须区分"精确"与"近似"

- 精确等价：存在 $T$ 使 $T(X)=Y$ **逐点成立**；
- 近似等价：存在 $T$ 使 $\max_i\|T(x_i)-y_{\pi(i)}\|\le\varepsilon$。

缺一个点、多一个点、有一个点的坐标有噪声——这些都属于后者。
README 第 13 节要求研究的正是二者的差别。把两者混在一个函数里，
Experiment D（压缩后还能不能识别）的结论就无法归因。

## 6. 已知的数值边界（必须随结论一起报告）

内部坐标的求解误差满足

$$\frac{\|\delta z\|}{\|z\|}\le\mathrm{cond}(M)\,\varepsilon .$$

于是：

- $\mathrm{cond}(M)\lesssim10^{6}$ 时，$10^{-9}$ 的精度可以达到；
- 更扁的标架只能达到 $\sim\mathrm{cond}\cdot\varepsilon$，库会**报告**这个界而不是假装满足 $10^{-9}$；
- 另有一个与条件数无关的失效模式：
  $\max\|\Delta\alpha\|\approx\varepsilon\|t\|/\|B-A\|$，
  它由**平移幅度**决定，发生在输入被舍入的阶段。

详见 [`theory/numerical_limits.md`](theory/numerical_limits.md)。

```text
① 同一个图形移动以后坐标全部变化
                ↓
② 所以绝对坐标不能作为视觉对象的可靠描述
                ↓
③ 用图像自己的三个点建立内部坐标系
                ↓
④ 对图像进行旋转、缩放、剪切
                ↓
⑤ 外部坐标变化
                ↓
⑥ 内部仿射坐标保持不变          ← 项目核心，已实测：2.2e-14
                ↓
⑦ 利用这种不变量构造图像代码     ← Phase 3（待确认教材定义）
                ↓
⑧ 使用代码识别仿射等价图像       ← Phase 4
                ↓
⑨ 对点集压缩后重新进行识别       ← Phase 5
                ↓
⑩ 最后从左右二维投影恢复三维结构 ← Phase 6
```
