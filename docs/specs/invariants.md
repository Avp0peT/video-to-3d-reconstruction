# 规格 M6：不变量实验中心

README 第 9 节要求：

> 每一项必须能通过实际数值实验验证，而不仅仅展示文字。

本规格说明「验证」在实现上意味着什么。

## 1. 两类性质，两种测量方式

README 的表格混合了两类**数学性质不同的**对象，用同一种方式测量会造成方法论错误。

### 1.1 连续量（continuous quantities）

| 性质 | 测什么 | 判据 |
|---|---|---|
| 绝对坐标 | $\max_i\|x_i-y_i\|$ | 相对图像尺度 |
| 距离 | $\max_{i<j}|d_{ij}-d'_{ij}|$ | 相对图像直径 |
| 角度 | $\max\|\theta-\theta'\|$（弧度） | 绝对 $10^{-9}$ rad |
| 长度比例 | $\max|r-r'|$，$r=d_{ij}/d_{\max}$ | 绝对（已归一化） |
| 仿射坐标 | $\max(|\Delta\alpha|,\,|\Delta\beta|)$ | 由条件数决定 |

判据必须**带尺度**：$\|x\|$ 量级的坐标只能分辨到 $\mathrm{ulp}(\|x\|)$，
固定绝对阈值在大坐标下过松、在小坐标下过严。

### 1.2 关系量（relations）

共线性与平行性**不是数值量**，而是关系：

> 仿射变换**不保持**两条线段的夹角，但**保持「平行」这个事实**。

因此正确的测量对象是**关系集合**：

| 性质 | 关系 | 见证形式 |
|---|---|---|
| 共线性 | 共线三元组集合 $R_{\text{coll}}(X)$ | 索引三元组 $(i,j,k)$ |
| 平行性 | 平行线段对集合 $R_{\text{par}}(X)$ | 索引四元组 $(i,j,k,l)$ |

判据是**集合的对称差是否为空**。

若错误地对平行性测量"线段夹角"，在剪切下会得到"不保持"的结论——
与 README 表格相反，而且是测量方法错，不是数学错。

## 2. 三态结论：`preserved` / `violated` / `vacuous`

朴素的关系判据在**两个集合都为空**时返回"保持"。这对随机点集几乎总成立
（随机三点恰好共线的概率为 0），于是结论**不是**「性质保持」，
而是「**什么都没测**」。

这类结论会同时产生两个后果：
① 报告里出现没有信息量的绿色；② 一个完全损坏的实现也能全绿。

因此本模块规定三态：

| 结论 | 含义 | 界面 |
|---|---|---|
| `preserved` | 性质保持，**且原本存在见证** | ✓ |
| `violated` | 存在失败见证 | × |
| `vacuous` | **无见证，此结论无信息量** | – （灰） |

实现细节：每个关系行同时报告 `value_before`（原图中该关系的规模）。
`value_before = 0` 时不允许返回 `preserved`。

对应测试：`test_shape_without_collinear_triples_is_reported_vacuous_not_preserved`
（正七边形没有共线三元组，必须报 `vacuous`）。

## 3. 可证伪性：每个性质都必须能"失败"

| 性质 | 保持于 | 必须失败于 |
|---|---|---|
| 绝对坐标 | 恒等 | 平移 |
| 距离 | 平移 / 旋转 / 反射 | 相似（$s\neq1$）、缩放、剪切 |
| 角度 | 平移 / 旋转 / 反射 / 相似 | 非等比缩放、剪切 |
| 长度比例 | 平移 / 旋转 / 反射 / 相似 | 非等比缩放、剪切 |
| 共线性 | 全部仿射 | — （对**无关图像**必须失败） |
| 平行性 | 全部仿射 | — （对**无关图像**必须失败） |
| 仿射坐标 | 全部仿射 | — （对**无关图像**必须失败） |

最后三行的"无关图像"是**控制组**：把图像与一个同基数的随机点集比较，
所有行都必须判 `violated`。否则说明关系测量恒返回空见证集。

测试：`test_unrelated_images_break_every_relation`；
实验证据：`experiments/exp_invariant_table.py` 的 `UNRELATED_CONTROL` 行。

## 4. 逐点对应：明确的方法论边界

所有连续量的比较都使用**调用方给定的索引对应**：第 $i$ 个变换后点是第 $i$ 个原点的像。

这是合法的，因为实验室**自己施加**了变换，对应关系是已知的。
必须明确写下来，因为它与 Phase 4 的**识别问题**（对应未知）是不同难度的两个问题：

| 问题 | 对应 | 难度 |
|---|---|---|
| 不变量验证（本模块） | 已知 | 直接代入 |
| 仿射等价识别（Phase 4） | **未知** | NP-hard 方向，需枚举 |

把两者混为一谈会让「不变量成立」被误读为「识别已经解决」。

## 5. 角度测量必须用 `atan2`，不能用 `arccos`

$$\theta=\arccos\frac{u\cdot v}{|u||v|}\ \Longrightarrow\
\frac{d\theta}{d\cos\theta}=-\frac{1}{\sqrt{1-\cos^2\theta}}$$

在 $u,v$ **近乎平行**时（即近乎共线的三元组——正是点集图像中最常见的情形）
该导数发散：$\cos$ 的 $10^{-16}$ 误差被放大成角度的 $\sim10^{-8}$ 误差。

后果：对纯**平移**的图像（应当角度完全保持）会报"角度不保持"，
纯粹因为平移后原本与坐标轴对齐的共线点不再是精确的 $\cos=1$。

正确实现：

$$\theta=\mathrm{atan2}\big(|u\times v|,\ u\cdot v\big)$$

近平行时第一个参数是 $O(\varepsilon)$、第二个是 $O(1)$，$\mathrm{atan2}$ 对小角度天然精确。

回归测试：`test_angle_change_detects_a_known_rotation_of_45_degrees`
（45° 旋转必须给 $<10^{-12}$，$45°$ 剪切必须给出 $\pi/4$）。

## 6. 复杂度保护

| 量 | 组合数 | 保护 |
|---|---|---|
| 角度 | $3\binom{n}{3}$ | `max_points`（默认 30） |
| 共线性 | $\binom{n}{3}$ | — |
| 平行性 | $\binom{\binom{n}{2}}{2}$ | 硬上限 24 点 |

超出上限必须**抛错**并说明原因，而不是静默截断（静默截断会让「保持」结论
变成对某个未知子集成立，无法复现）。

## 7. 实现输出

`InvariantReport` 提供：

- `verdicts()`：`{property: verdict}`；
- `as_rows()`：界面表格所需字段；
- `to_json()`：实验存档；
- `markdown_table()`：README 第 9 节表格的**实测版**（含 max|Δ| 与容差列）。

`report_for_transform(x, transform)` 是推荐入口：它自己施加变换，
并从变换对象取 `classify()` 作为类别标签——**不猜**。

`invariant_report(x, y)` 允许不给变换对象，此时用三个控制点拟合仿射变换并分类；
拟合残差超容差则返回 `"unknown"`。该路径**仅供 GUI 手动编辑模式**使用，
不得用于实验——实验必须显式传入变换标签。
