## 4. 已裁决边界与未决实现（详见 [open_questions.md](open_questions.md)）

1. P4：按来源和语义隔离两版 `остов`；保留旧公开 API，新增可用 `Ostov2025M`。设计已定，实现待做。

4. P2 / T04：最小面积外接椭圆可使用 NumPy，按需在隔离环境锁定 SciPy；`fitEllipse` 不能替代。

## 5. 方法注记（本次踩到的两个测量陷阱，务必沿用）

1. **`grep` 会把 PDF 抽文判为二进制**，输出 `Binary file … matches`（1 行）
   ⇒ `grep -o … | wc -l` 得到**恒为 1 的假计数**（本会话第一次统计时 14 个术语全为 1）。
   术语统计一律用 Python。
2. **未加词干的子串会漏掉屈折形式**：`метка` 漏掉 *меткой/метки*、`группа` 漏掉 *группы/групп*。
   本次修正后 `групп` 由 26 → **111**、`метк`(2025) 由 0 → **2**。
   词干也会把不同词计在一起（如 `метк` 与 `разметка`）；统计结果须回到上下文复核。
3. 零计数可能来自词形、编码、抽取或检索词选择；它不能证明概念不存在。正计数也不能证明同义、首次出现或唯一出处。
