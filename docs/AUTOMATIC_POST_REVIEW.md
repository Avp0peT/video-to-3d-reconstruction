# 自动建模后复核

照片或视频通过 `scripts/run_photo_demo.py run` 建模后，默认自动执行离线复核，并在主报告中提供“自动离线复核（非建模验收）”卡片。无需手工追加研究步骤；复核没有可用模型时也会记录数据不足原因。`--post-review` 显式开启，`--no-post-review` 关闭；建模入口与已有参数见 [照片/视频使用说明](PHOTO_DEMO_USAGE.md)。

## 复核已有任务

在项目根目录使用已有轻量 Python：

```powershell
python -B -X utf8 `
  scripts/review_photo_model.py --pipeline 'C:\path\to\pipeline'
```

省略 `--output` 时，在 pipeline 的父目录创建全新的 `post_review_<UTC时间>_<唯一ID>` 兄弟目录。也可明确指定全新输出路径：

```powershell
python -B -X utf8 `
  scripts/review_photo_model.py --pipeline 'C:\path\to\pipeline' `
  --output 'C:\path\to\new_review'
```

输出目录不能已存在，不能覆盖原任务或其祖先目录，也不能进入照片、SfM、SAM3来源目录。主流程内部仅保留精确的 `pipeline/post_review` 自动输出位置。复核不会调用 SAM3、SfM 或 MVS，也不会重新拟合相机或修改模型、点、掩膜、孔洞。它读取当前主流程的来源与模型选择，复制发现状态到 `DISCOVERY.json`，随后绑定需要核查的输入。

## 内容与边界

复核检查已有多视图对应及外观证据：排除候选及坐标别名后拟合 fundamental 约束、预设近邻交换候选、其他原始轨迹视角，以及描述子和固定图块。最多选取一个模型中的12个注册视图，按输入顺序均匀取样；若遗漏视图会隐藏坐标别名关系，则拒绝评分并说明原因。最多4096条相关轨迹，超过则明确记录数据不足，不偷偷截断点。最多10图对按共享 singleton 轨迹数量排序、图像ID打破并列，不按残差挑选结果。

图块半径8和16分别报告，固定中心双线性采样，不搜索、旋转补偿或选取“最好”半径。图块越界、穿过目标掩膜边界或数值上没有纹理时明确不给评分。ZNCC和归一化描述子距离只提供外观相似性支持，不是概率或对应真值。

原始像素保留镜头畸变，因此 fundamental 的 Sampson 残差仅为近似诊断。预设交换是敏感性控制，不能换算错误检测率或准确率；额外视角沿用原轨迹，证据存在相关性，两候选也可能都错误。不同模型族的指标不能当作相同自由度的算法排名。复核不提供物理尺度、几何精度或CAD验收。

## 目标内选点覆盖

默认复核还输出 `point_coverage/index.html`。其依据是用户提供书稿《Сборка макета》的印刷页118–120：从有限点集 A 选取子集 A_r，使 A 中每点距某个代表点不超过 r。本实现是确定性的最远点贪心覆盖，不声称获得最小基数的 `остов`，更不是语义分割或物体中轴骨架。

三组观测独立报告：目标掩膜内全部原生特征、至少2个不同注册视图的轨迹观测、至少3个不同注册视图的轨迹观测。保留原生浮点像素和 feature row / point3D ID；不移动点，不发明对应。掩膜查询取 floor(x),floor(y)；覆盖栅格用像素中心 (列+0.5,行+0.5)。单视图多观测歧义来源由主入口拒绝，不静默选一个。模块依赖主入口完成来源身份、格式与输入前后哈希核验，不是独立数据认证器。

半径固定为图像长边1024时的16、32像素，两档都报告。每组分别验证“已有有限点集是否被代表点覆盖”和“全部点/代表点的圆盘覆盖了多少目标mask像素”。前者完整不代表后者完整，也不代表三维正确。图中绿色为原始点附近的目标像素，红色为缺少附近观测的目标像素，黄色为选出的代表点。阈值只是诊断配置，未标定为精度或验收门槛。

单次cover最多20000输入点、4096代表点，栅格最多400万像素、每次圆盘扫描最多1亿次包围盒像素访问；超限明确记录原因。保留原点集及每点最近代表点、距离见证；覆盖图写出后逐像素回读。缺mask、无目标或无法评估保持独立状态。

## 表面观测支持

若主流程存在同一次MVS运行绑定的稠密点云与选定原始网格，自动生成 `surface_support/index.html`。数据从 `surface.evidence_paths` 中的生产记录解析，核对模型产物路径、bytes与SHA256；不靠猜测文件名寻找点云。

统计所有三角面的边长、面积和最长边前1%面的面积占比；确定性抽取至多256个普通面、前1%集合中的至多128个面，在面心和三个边中点计算到稠密点的最近距离。另取至多256个稠密点估计最近邻间距，两者都保留样本ID、原单位数值与采样规则。最近邻工作量有2亿次点对上限；PLY文件各限64MiB，最多10万稠密点、20万网格顶点/面。

支持距离仅描述样本离已保存稠密点多远，不是遮挡检查、真实表面距离或完整网格证明。没有经过验证的删面阈值，因此本模块只报告，不删除三角面、不补孔、不改Blender模型，也不改变CAD或几何验收状态。缺来源为 `NOT_AVAILABLE`，格式/绑定/预算失败为 `NOT_EVALUATED`，已测为 `DIAGNOSTIC_ONLY_NOT_ACCEPTED`。具体缺陷是否可通过补拍、补匹配或重建改进仍需后续实证。

## 视频采样帧的连续候选轨迹

视频任务还可检查已有抽帧图像上的连续候选轨迹。PPP 当前使用已提交的72张抽帧，不是原视频192张解码全帧；输入顺序来自已绑定的帧身份和时间记录。该步骤不重新抽帧、不调用SAM3或SfM、不改变原对应或模型。

固定CPU OpenCV LK分别执行正向和反向pass，两个方向使用不相交轨迹ID，不拼接、不合并，也不当作两份独立真值。最多96帧、长边1024、256个活动点，每帧最多1024个真实corner候选。只有已绑定目标mask时才在向内腐蚀10px区域新增corner；书中的r-cover用于覆盖这些已有候选点，半径按长边归一化为16px/1024，不制造插值种子，也不声称最小ostov。覆盖预算不足明确保留PARTIAL。

前后向LK误差须不超过原图尺寸的1px；状态失败、非有限、越界或已知目标mask拒绝均永久终止该ID。未知mask可探索最多连续12步，其观测保持TARGET_UNVERIFIED；恢复后新种子使用新ID，不自动复活断轨。输出xy为canonical像素中心，即OpenCV整数像素中心坐标加0.5。

新复核会追加 `RECOVERY.json`、`RECOVERY_ASSESSMENT.json` 与 `reassociation/index.html`，检验断轨后新种子是否可能对应旧端点。原始 `TRACKS.json` 和其ID、观测不改写；独立生成带 `source_track_ids` 的候选连接链。每条链只包含原有实测观测，中间缺失仍为UNKNOWN，不插值、不自动归因为遮挡。

固定候选范围为同一方向的末端与新种子，相差2至6个已有采样帧（中间缺失1至5帧）。两端必须有目标mask且完整15×15子像素纹理窗口受其支持；跨间隔前后向LK≤1px、预测到实际种子≤2px、从实际种子独立反向到旧端点≤1px。双侧候选分离差至少4px；局部灰度标准差≥5、ZNCC≥0.85，16px内存在相关性相近的其他实际端点则拒绝。跨所有允许间隔检查唯一入边/出边，出现竞争不强制挑一个。以上均为实验诊断门槛，不是物理点身份或精度标准。正、反向候选仍分开。

新增候选的几何检查只用原始、未加入连接候选时已经得到且通过留出诊断的F；不重新拟合F后自证。若候选任一端距原训练端点≤2px，标记TRAIN_ENDPOINT_DEPENDENT，不计独立支持；无原F或无可用证据则保留NO_INDEPENDENT_GEOMETRY。其余报告Sampson残差及H平面/低视差歧义，即使候选获支持也不直接拼接原生模型。当前只补齐可检验的跨断点重识别候选；接入重建仍需多视图和三角化可观测性验证。

候选空间索引保留完整端点集合，不按数量截断；200万次距离计算预算按实际访问并计算距离的端点收费。近邻分离用6/6/5px搜索半径，纹理竞争用16px；这些半径覆盖判据需要的所有竞争者。邻域外次近邻只记null及距离下界，不伪造全局最小值。报告中的拒绝次数按端点或图对尝试累计，同一点可能在多个间隔被检验，不能当作互斥物理点人数；无候选也是诊断结果。若 `patch_comparisons=0`，表示未进入纹理检查，不能据此归因于纹理阈值。

已知mask端点上的F留出检验与H（单应）候选分别报告；它们是对冻结观测的条件化诊断，不把未知区间认证为物体身份，不拼接候选成新SfM模型，也不以数值较低自动改对应。运动跟踪、投影约束通过和真实几何验收是不同阶段。

固定依赖是`opencv-python-headless==4.13.0.92`，wheel SHA256为`77a82fe35ddcec0f62c15f2ba8a12ecc2ed4207c17b0902c7a3151ae29f37fb6`，本地隔离目录为`outputs/toolchains/opencv-4.13.0.92`。仅显式从此目录加载，不安装、不联网、不改变Python环境；依赖或可用视频输入不存在时返回NOT_AVAILABLE及原因。CPU固定关闭OpenCL、线程2、RNG seed0。

独立入口必须指定全新输出，建议使用pipeline的兄弟目录；入口和模块均检查来源目录边界：

```powershell
& 'outputs/delegation/T02A/envs/20261002T190239Z_9b9b5ddb/venv/Scripts/python.exe' -B -X utf8 `
  scripts/track_video_correspondences.py --pipeline 'C:\path\to\pipeline' `
  --output 'C:\path\to\new_temporal_review'
```

退出码0为DIAGNOSTIC_COMPLETE（候选诊断完成，非建模认证），1为NOT_AVAILABLE，2为FAILED或输入/输出校验错误。该独立CLI不包含主线的进程监督配额。

## 产物、状态与资源

### 共同可见子图候选

视频自动复核新增 `temporal_tracks/partial_subimages/index.html`。书稿印刷61–62页提供三点仿射假设、额外点和整组码检查的思路；本实现是**局部仿射的浮点工程近似**，不冒称书中精确算法认证，也不把任意非平面透视当仿射。

读取已绑定SfM数据库的原生SIFT行，沿image.name、frames_map、input_index核对身份；只使用已提交目标mask内点。每帧最多256行，按原行号确定性均匀采样，遗漏行全部登记。坐标沿用COLMAP的canonical像素中心，不再次加0.5；已归一化且量化的128维描述子只转浮点后逐行L2，不重复开平方。重复坐标别名和零描述子明确排除。互为前2近邻且L2≤0.75提出边；第2/3名并列则拒，最多48边，剩余边另记，不能据此声称完整搜索或物理唯一。

最多24图对（先相邻有效mask帧，再均匀取跨4个有效帧图对）；每对最多512个三边组合，超出时确定性采样并标记非穷尽。两侧三角面积至少32px²、条件数≤50；双向映射误差≤2px、距对应侧锚点之一≤160px。全部合格几何边保留，再从各锚点假设的“3锚+3额外点”组合虚拟域中，全局等距选择最多512个六点子集；记录局部/全局组合身份、未选几何边和未匹配原点。固定六点只限定本实验，不冒称搜索了所有大小的共同子图，也不因合格点太多而拒绝整组。任一阶段采样或输出上限触发均明确非穷尽。

每个候选内检查全部不同三角形的有序普通面积比（六点20个三角形，共380槽），epsilon=0.08，定义依据印刷21–22页；模式标记 `book-full-unsigned-area-v1`。55页允许的四点组缩短码为180槽，但书中未给缩短码与完整码在相同epsilon下数值等价的保证。历史v1使用signed四点组比值，保留旧产物，不能冒称380槽完整原码。两侧同标签分母均为0记录undefined；单侧为0拒绝；非零分母面积小于32px²记数值不稳定；无已定义稳定槽不得通过。阈值是工程稳定性规则，无物理精度含义。每个结果记录最坏槽的三角形标签、双方分子分母面积及比值。

书稿42–43页明确区分同一视向换投影面与改变立体的观察方向。非共面3D点在不同方向投影后一般没有统一2D仿射；因此该面积码仅筛选局部近似平面的子图，不能作为一般立体对应的必要门。自动复核新增 `proposal_geometry`：对全部已保留的描述子候选边检查原F，独立于面积码是否通过；汇总 `descriptor_geometry_counts`，不把F支持升级为物理身份或三角化授权。原始LK训练任一端2px排除、无模型原因与平面/低视差歧义均保留。

额外点和面积码参与搜索内检查，**不是独立留出真值**。补充诊断仅用原LK观测预先拟合的F，排除距训练端点≤2px者；不重新拟合F自证。多映射和歧义保留，未匹配点不自动叫遮挡/新表面点；第三视角的物理身份验证仍NOT_EVALUATED。无候选不代表视频中没有可恢复对应。全部结果保持candidate，不注入SfM、不补缺失观测、不生成或验收3D。特征源缺失或检查失败仅进入该子报告，不能借主诊断exit0宣称此阶段通过。

### 多视图闭环与身份冲突

同一入口自动追加 `partial_subimages/multiview_cycles/index.html` 和 `MULTIVIEW.json`。按用户指定顺序先核书稿，再查主文献：书稿41、53–54页的兼容对应要求，以及61–62页的共同子图思路提供约束；116–117页讨论不同点数及集合接近，仍要求每点有邻居，不等于任意缺失均可匹配。工程闭环补充参考 [Huang–Guibas 2013](https://geometry.stanford.edu/paper.php?id=hg-csmsdp-13) 和 [Chen–Guibas–Huang 2014](https://geometry.stanford.edu/lgl_2024/paper.php?id=cgh-sdpmom-14) 的多图映射相容思想。本实现没有实现其SDP优化或取得其恢复保证，不冒称书中精确恢复算法。

种子仅为前一步已保留且获原F支持的描述子边。节点使用 `(frame_index, native_feature_id)`；保留所有连通分量和同帧多特征身份冲突，不合并ID。全域计算三幅不同画面的两边路径数，中心可以早于或晚于两个端点；最多256条路径确定性全域采样。已存在三角分别计为3条路径、1个不同三角，不能混报。最多4096条图边，超限失败。

冻结路径后，最多8个缺失图对按排序均匀选取，从两帧**全部已选原生描述子行**重新运行相同的互为top2、L2≤0.75和48条保留上限；不只搜索预期的两个端点，不把路径复合当第三条边。仅一个补对pass，不递归扩展。已有图对复用实际原结果；未做图对、遗漏路径、预算截断的第三边均单独记录。第三边仍只对原F检查，训练端点排除与低视差歧义保持，不重新拟合。

新F支持边全部加入诊断图后重新检查连通分量的同帧身份冲突。三条边各自的竞争项包括保留边及被48条上限截断的合格边。闭环但有竞争记 `CYCLE_SUPPORTED_BUT_AMBIGUOUS`，无已观察竞争且三边均获F支持记 `CYCLE_SUPPORTED_CANDIDATE`；两者仍非物理身份、唯一性或三角化授权。无直接边不判具体哪条边错误，也不推定遮挡。图对由种子选择，属于条件化候选复核，不是独立统计留出。原TRACKS/GEOMETRY与SfM不改；`identity_verified=false`、`eligible_for_triangulation=false`、`native_injected=false`。

`direct-multiview-review-v2` 进一步写入 `competition_geometry_review`：保持原描述子歧义标签，另把几何竞争分开。相同 `(frame_a,frame_b,feature_a,feature_b)` 去重后复用retained原检查；最多256条尚未检查的已枚举竞争边按全域等距选取，用相同原F及训练端点排除规则检查。出现次数与不同边数量分别计，来源为retained或omitted逐项保留，不重新搜索特征、不增加F拟合、不递归补边。

新的F支持竞争也加入独立诊断图以传播同帧冲突。`NO_SURVIVING_COMPETITOR_IN_TESTED_SCOPE` 仅表示当前已枚举的竞争全部与冻结F不符（或当前没有竞争）；采样之外仍未知，唯一性保持 `NOT_PROVEN`。缺F、训练端依赖、预算遗漏和查询失败均为未解决竞争，不能当作被排除。F不符不是物理错误证明，F支持也不是身份真值。报告原描述子歧义与这一额外裁决两者，不能把旧 `CYCLE_SUPPORTED_BUT_AMBIGUOUS` 误读为所有替代边仍有几何支持。

存在直接闭环时，自动追加 `partial_subimages/candidate_observability/OBSERVABILITY.json` 及HTML。最多32个三边F支持闭环按全域均匀抽取；要求三帧在同一个可用且原生回读通过的模型中注册，并核对frames_map、源图字节、image/camera身份和原生特征行及xy，不把不同模型的同号camera_id混用。缺三帧共同模型姿态记 `MISSING_COMMON_MODEL_POSES`，不偷偷改成两视图。无三边F支持候选则不产生拟合结果。

数值方法复用标准固定相机DLT初始化和最多20次XYZ迭代，不改相机；记录原像素重投影、正深度、射线角和Jacobian秩，并轮换两图拟合、一图预测。摄像机已由原观测估计，因此这些仍非独立真值验证，也不是Kozlov平行投影构造。SIMPLE_RADIAL沿用已声明的两倍归一化图角半径逆域；负k若该完整域不单调则明确拒绝，不为获得坐标临时缩域。记录k、域半径、边界径向导数与转折半径；此拒绝不等于每个像素都无逆解。没有物理尺度或验收阈值，不输出新原生点云/网格/CAD。

每次新复核输出 `RESULT.json`、`index.html`、`PLAN.json` 和 `DISCOVERY.json`；有可评估案例时还输出 `GEOMETRY.json`、逐案例JSON和固定图块联系图。主报告核验复核RESULT及HTML的路径、字节数和SHA256，再提供链接。

- 退出码0：`DIAGNOSTIC_COMPLETE`，诊断完成，不表示建模验收。
- 退出码1：`INSUFFICIENT_DATA`，仍有原因报告。
- 退出码2：失败；已创建任务内的诊断失败通常仍有报告，参数或目录校验失败可能没有新产物。

自动阶段使用原冻结Python，由主线监督执行，120秒时间阈值、1GiB Job提交内存限制，不增加额外目录授权。时间/目录阈值是采样停止条件，不是精确硬配额。独立CLI没有这一层监督，需自行管理资源；不能将自动阶段的限制理解为独立CLI已强制执行。

用户取消、前阶段资源停止或进程未确认回收时，主线分别记录 `NOT_RUN_CANCELLED`、`NOT_RUN_RESOURCE_LIMIT` 或 `NOT_RUN_UNRECLAIMED`，不再启动复核子进程；主报告仍保留原因。复核失败只留在独立阶段，不覆盖主流程失败原因，不改变已有表面/CAD成果的验收状态或主线成功判据。

### 主点、畸变假设及单应风险的条件留出检查

内参稳定性报告成功后，自动复核继续运行 `intrinsics_sensitivity` 子项；
独立入口为 `scripts/review_intrinsics_sensitivity.py --intrinsics <INTRINSICS.json> --output <新目录>`。
它复核上一份报告的全部来源与实现哈希，读取同一只读数据库，不重新匹配、运行BA或写回相机。
独立入口沿用120秒、1GiB、2线程监督；报告保存在 `report/index.html`、`report/SENSITIVITY.json`。

主点敏感性仅对原F试探中心、cx±2%宽、cy±2%高共5种设置。每种保留原101点焦距曲线。
这些偏移是固定诊断场景，不是主点误差置信区间；最低值落在边界仍保留边界状态。

径向敏感性固定数据库初始f和主点，分别采用SIMPLE_RADIAL的k=−0.1、0、+0.1；
逐点在中心单调分支内反解，并回代检查。它不是线性变换F，不声称这三值覆盖真实镜头范围。
随后按原特征ID字典序作偶/奇两折，每折至少12个训练点和12个留出点；不满足时写INSUFFICIENT。
分别用训练点拟合归一化八点F、归一化DLT单应H，以及参考K下的射线旋转R。
每折输出训练与留出特征ID、矩阵、留出残差和无效预测数；不重新筛内点或选择最佳k。

F使用校正像素域的Sampson平方根，H使用双向传递RMS，二者数值不能直接作为模型选优依据。

不把缺失当作“不相容”。R只报告依赖参考K的角残差，不宣称它是三角化视差。

H相容不能区分平面、纯旋转、远景、小基线等；H不相容也不能单独证明有足够深度约束。

产物保持 `calibration_accepted=false`、`new_ba_authorized=false`、
`adequate_triangulation_parallax=NOT_ESTABLISHED`，不把主点和k的分开试探说成联合标定。
