# 物体局部取点密度

目标是避免总点数很多、局部却缺少观测。密度达标与对应正确、形状正确是不同判据。

## 自动采样

新建 `reconstruct-regions` 任务的冻结 PLAN 含 `density_policy`。正向与反向区域跟踪都读取该策略；历史计划缺少该字段时保留原先采样行为，不改旧记录。新策略在每帧跟踪后检查欠密度区域，允许中间帧出生新候选 ID，不补造丢失区间。

- 在当前 SAM 掩膜的包围框内划分 8×8 单元，网格随掩膜移动。背景不参与密度分母；每一个有前景的边界单元都参与。
- 完整单元目标为 4 个不同像素位置；边界按前景占该单元面积比例向上取整，最少 1 个、不超过前景像素数。默认值只是工程起点，不是论文定理、毫米精度或普适最优值。
- 先轮流满足各欠密度单元的配额，再取额外特征。每单元每档最多 32 个真实角点候选；角点响应门槛依次为 0.01、0.003。第二档仅补仍不足单元。
- 21×21 纹理块、纹理标准差≥2、掩膜支撑≥0.85、7 像素间距、600 活跃点上限保持不变。降低的是检测候选门槛，未降低 LK 前后向 1.5px、ZNCC 0.8 或下游几何条件。
- 没有足够真实角点或达到资源上限时，记录 `BELOW_DENSITY_TARGET`；不放置规则网格假点，不将候选当成成功匹配。每帧补点有预算，帧提交仍只保留真实 endpoint 观测。

## 覆盖率复核

`surface-regions` 完成现有表面导出后自动生成 `point_density/index.html`。对已有表面可单独运行，无需再次分割、跟踪或建模：

```powershell
& <项目Python> -B -X utf8 scripts/run_photo_demo.py audit-point-density --run <区域表面目录> --output <全新报告目录>
```

报告同图显示三层：旧版候选、新版独立逐帧候选、原始模型的实际三角化观测。最后一层仅计入互惠 track、至少两个视图、正深度、回投影≤2px 的原观测，并从 COLMAP 的半像素坐标变换到 OpenCV 像素中心；不将任意背面三维点投影来冒充可见支撑。

每帧保留单元目标/数量/缺口、满足配额单元的前景面积比例、最大四连通欠密度区域占物体掩膜面积比例。该面积比例不是点覆盖的连续表面积，也不说明一个单元内部完全均匀。密度评估以当前掩膜为条件，掩膜遗漏或误包含仍会影响结果。

检测进程 exit 0 只表示报告完成；业务状态单列。候选通过率不替代三维观测覆盖，稀疏覆盖不替代稠密可见表面覆盖。`dense_visibility_coverage=NOT_EVALUATED`。密度不足的局部表面仍可供诊断，但不能因此获得整体完整性验收。

`followup_regions` 自动列出待补区域。报告内的新候选没有自动加入已有模型；是否确实增加了有效三维点，需要下一次正常匹配、三角化和表面流水线验证。有限图像不能保证每个表面都有可靠观测。

## 由同一输入实际重新建模

已有含 `input/PLAN.json`、`geometry/RESULT.json` 的区域任务，可自动完成新跟踪、重新验证对应、三角化、局部表面、Blender及密度复核：

```powershell
& <项目Python> -B -X utf8 scripts/run_photo_demo.py rebuild-density-model --run <旧区域任务目录> --output <全新目录>
```

时间轴、端点、图像/掩膜、已有SIFT原始匹配均保持相同。新独立输入计划增加 `density_policy` 与 `identity_policy`，不会重新选择端点或重新分割。历史密度实验只含前一项，新版本不再是“仅修改密度”的对照。跟踪与几何各600秒/4GiB、CPU2线程；表面阶段另用已有监督器和预算。每阶段只尝试一次，不因失败自动调参重跑。新几何放在 `reconstruction/`、表面和 Blender 在 `surface/`。只有新几何真实产出后才运行表面；历史模型不作替代。多个分量仍独立，仅选择注册视角最多的分量构建局部表面。

## 跟踪身份冲突与表面支撑

`rebuild-density-model` 自动启用 `object-track-identity-v1`。原前后向光流、纹理、掩膜检查通过后，若两个不同区域轨迹 ID 在目标帧相距不超过 1px，两者均结束，不提交本帧歧义观测。此前的有效轨迹保留，之后补点使用新 ID；不按分数选赢家、不合并旧 ID、不填造断点。几何导入再次检查相同策略，避免绕过跟踪检查。1px 是当前像素域的工程歧义阈值，不证明两个位置是同一物理点；该检查不覆盖原始 SIFT 与区域点之间的竞争，也不保证排除长程漂移。

表面流程自动增加 `support_audit/index.html`。它检查固定数量的大面片内部和长边中点到完整稠密点云的距离，并对照普通面片、以局部点间距归一化。稠密点是估计结果，不是真值；近邻距离不能证明可见性或物理连接。状态始终为 `DIAGNOSTIC_ONLY`，不自动删面、不替代形状验收。对现有区域表面可独立执行：

```powershell
& <项目Python> -B -X utf8 scripts/build_region_surface.py support-worker --source <区域表面目录> --output <全新诊断目录>
```

2026-10-23 同一1089帧/88端点的真实跟踪对照：区域轨迹端点的≤1px冲突对数由46降为0，平均活跃点410.57→408.65（约−0.47%）。本次仅运行跟踪，未重建三维模型；不是“错误对应率为0”或“粘连已修复”的证据。

## 依据与边界

书籍已缓存的 `track_recovery_20261015/book_review/BOOK_REVIEW.md` 讨论印刷61–62页的共同子像与附加点一致性；它不提供以上密度阈值，也不保证弱纹理或遮挡区可恢复。

- OpenCV 官方 `goodFeaturesToTrack`：`qualityLevel` 控制角点响应阈值，`maxCorners` 是上限，`mask` 限制检测区域，不保证返回最低数量。https://docs.opencv.org/4.5.2/dd/d1a/group__imgproc__feature.html
- COLMAP 官方 FAQ：弱纹理可尝试更高输入分辨率和更大块窗口；属于需要验证的后续选择，本轮没有改变稠密重建器参数。https://colmap.github.io/faq.html
