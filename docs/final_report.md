## 3. 核心结果

### 3.1 内部仿射坐标的仿射不变性（项目核心）

**结论**：$\alpha,\beta$ 在一切可逆仿射变换下不变。

**证据**（Experiment A，1000 次随机仿射变换，标架随图像一起变换）：

| 量 | 实测 | 要求 | 理论界 |
|---|---|---|---|
| $\max\|\Delta\alpha\|$ | $2.243\times10^{-14}$ | $<10^{-9}$ | $1.655\times10^{-12}$ |
| $\max\|\Delta\beta\|$ | $2.109\times10^{-14}$ | $<10^{-9}$ | $1.655\times10^{-12}$ |

- 通过余量：相对要求 $4.5\times10^{4}$ 倍，相对理论界 $73.8$ 倍；
- 中位误差 $6.7\times10^{-16}$，已达机器精度；
- 全程 0.12 秒。

**这只是"机制成立"，不是"机制产生收益"。** 本项目第二阶段的目标才是后者。
本阶段的结论**不能**用来声称任何性能优势。

### 3.2 不变量表的实测版本与 README 理论表逐格一致

`experiments/exp_invariant_table.py` 的输出与 README 第 9 节表格
逐行逐列一致（8 个变换族 × 7 个性质）。

**控制组**：与同基数随机点集比较时，7 项**全部**被破坏。
这一行的存在使得"前面 8 行的 ✓"具有信息量——否则一个恒返回"保持"的实现也能全绿。

### 3.3 关键否定结果（本阶段最有价值的部分）

| # | 发现 | 影响 |
|---|---|---|
| 1 | `1e-9` 只在 $\mathrm{cond}\lesssim10^{6}$（flatness $\gtrsim10^{-6}$）时成立；flatness $=10^{-8}$ 时实测 $1.35\times10^{-8}$ | README 的验收标准必须带条件引用；库改为报告可达精度 |
| 2 | 存在与条件数无关的失效模式：$\max\|\Delta\alpha\|\approx\varepsilon\|t\|/\|B-A\|$ | 跨坐标量级比较必须额外加该项 |
| 3 | 顶点正弦 $|\sin\angle BAC|$ **不是**置换不变量，不能用来定义"共线"关系 | 改用置换不变的 flatness；否则 Phase 3 的编码会依赖索引顺序 |
| 4 | 条件数预算若用标量缩放实现则完全失效（$cA$ 与 $A$ 条件数相同） | 改为钳制奇异值；实测由 55.4 → $\le50$ |
| 5 | $\arccos$ 在近平行处导数发散，会把纯平移误判为"角度不保持" | 改用 `atan2` |
| 6 | 存在舍入恰好抵消的配置（15 组中 3 组误差塌到 $10^{-16}$） | 报告必须用多配置最大值，不得引用单次样本 |

第 3、5 项由 Hypothesis 在随机样本中发现，人工构造的用例不会遇到它们。

### 3.5 Q1 取得实质进展（但仍需一项裁定）

**已取得正式「код изображения」定义的逐字文本**：

$$\langle M_A,\ T_A\rangle,\qquad T_A=\{\,S_{mnu}/S_{ksp}\,\}\ \text{（遍历所有三元组对，分母非退化）}$$

来源为 **Kozlov 本人专利说明书 RU2779379C1**（作者自撰、可实施、且把定理归给教材 МГУ 2007）；
2009 年论文摘要（出版社页面）独立确认编码的仿射不变性。

G3.1–G3.7 七个 Gate 中 **6 项明确满足**，唯一开口是 **G3.1 的来源层级**
（专利能否替代教材作为一手依据）⇒ 需项目负责人裁定。

```text
Phase 3 = LOCKED（待 G3.1 裁定）
```

**同一轮还发现了一个对实现有决定性影响的数值事实**：字面执行源定义的分母判据
$S_{ksp}\ne0$ **不可用**——数学上共线的三元组在浮点下给出
$\sim10^{-16}$ 的伪非零面积，使 $\max\rho$ 达到 $3.07\times10^{16}$，
并且**一次纯平移就会改变它**。改用无量纲的 flatness 判据后，5 数据集 × 8 族全部通过
（$9.5\times10^{-14}$）。详见 `docs/specs/official_image_code.md` §13。
