## 上一批2002／2009可运行构造（14模式为历史时点）

研究页面 `app/pages/12_Exact_Research.py` 新增三种模式，合计14种；使用完整JSON输入，点击才执行，结果可无损下载并独立核验。

1. **固定朝向与给定对应最优平移**：每侧1–32个不同有理二维点、显式双射、有理正交Q。特征核允许重复，枚举1/2/3点圆支撑；返回唯一平移和误差平方。反射是同一归约的明确扩展。
2. **给定位置接受性**：精确阈值图；普通接受与狭义接受分开。每点都有邻居仍可能不存在双射，负结论用完整Hall亏缺见证证明。
3. **给定位置瓶颈匹配**：在全部有限边长阈值中寻找双射最小最大距离。上界匹配+紧邻较小阈值的不可行证明一起核验。位置不变，未搜索旋转或平移。

证明及来源页见[推导](derivations/fixed_orientation_minimax.md)，输入/证书契约见[平移](contracts_fixed_orientation_registration_v1.md)和[匹配](contracts_placed_candidate_matching_v1.md)。示例包括“均值平移不是minimax”、三支撑圆、有理旋转、Hall反例及固定位置瓶颈。反例/篡改测试、独立核验与GUI运行各自报告。
