# 固定朝向与对应的最优平移：实现和核验证明

来源：S-2002 打印页258定理1，S-2009 打印页102定理5及其后的 characteristic image / key circle 构造。原文已有最小包含圆归约；下述有限支撑枚举、预算与证书格式是项目实现选择。页面图像核对记录在 `outputs/delegation/KOZLOV_LEGACY/20261014_author_algorithms/source_views/`。

设输入为完整有限点集，给定双射 m 以及固定正交矩阵 Q；实现方向是 `Q(source_i)+t` 对齐 `target_m(i)`。令 d_i=Q(source_i)−target_m(i)。目标为最小化 max_i ||d_i+t||²。它等于特征核 {d_i} 最小包含圆的半径平方，平移为其圆心的相反数。重复核向量可以存在，原输入标签不能丢失。

在平面中，最小包含圆可由1、2或3个边界点支撑，圆心属于这些支撑点的凸包。实现枚举三种支撑，排除共线三点和负重心权重，再检查所有核点包含性。输出有理圆心和有理半径平方，不计算近似平方根。3点支撑枚举不是对任意旋转或对应的搜索。

独立核验给出直接下界：设证书支撑点为 d_j，权重 λ_j≥0、Σλ_j=1，圆心 c=Σλ_j d_j，支撑点都满足 ||d_j−c||²=r²。对任意备选圆心 z，

    max_i ||d_i−z||² ≥ Σ_j λ_j ||d_j−z||²
                          = r² + ||z−c||² ≥ r²。

全点包含给出在 c 的上界r²；两者相等证明全局最优，且 z≠c 时严格增大下界，证明平移唯一。核验器只做上述回代与凸组合恒等式，不调用枚举器或构造器。

固定有理反射Q同样满足这个归约；它是项目明确声明的扩展，不是原文固定旋转角家族的逐字复现。输入上限32点、256位有理数以及工作/时间预算属于计算域约束，预算耗尽只给UNKNOWN。

# 给定位置的接受性与瓶颈匹配

S-2009打印页106–107对已产生的候选位置，按距离阈值建立双方邻接。每点至少有一个邻居是普通接受；同基数时存在完美匹配是狭义接受。原文106页第二个邻域的目标集合有排印歧义，107页明确为A中的点；实现采用对称二部关系。

正证书给出全部标签上的双射；负证书给出Hall亏缺集合S及其**完整**邻域N(S)，核验|N(S)|<|S|。只验证某个匹配不完整不能证明不存在完美匹配。实现的增广路径和Hall见证属于这些有限谓词的项目实现。

给定位置下，最小瓶颈平方距离必取自有限的两两距离平方集合。证书在候选最优值给出完美匹配，在紧邻的较小候选值给出Hall亏缺；若已是最小边值，则任何更小阈值都无边。阈值单调性证明对所有双射的最优性。独立核验重算全部距离和阈值，但不运行匹配搜索。

这些结论不证明该候选位置优于其他平移/旋转，也不实现S-2009完整候选位置U/U₀的生成，更不把固定位置Hausdorff距离写成S-2002等距商空间的距离。
