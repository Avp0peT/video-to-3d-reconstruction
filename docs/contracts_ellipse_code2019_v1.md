# 2019 椭圆代码：精确比值与几何证书

来源S-2019-CODES，打印页59，引理1和随后的椭圆代码定义；原文PDF及页图像见来源登记与`20261014_author_algorithms/sources/`。不是把先前2025整个中心算法改名为2019算法。

## 原文思想与实现

非退化三角形经可逆仿射变換化为等边三角形，其最小面积外接椭圆化为外接圆。椭圆面积与三角形面积有共同常数比。因此，对两个非退化三角形，椭圆面积比等于三角形面积比；π和根号常数在比值中抵消，无须数值优化。

`build_ellipse_code2019(points, *, max_work=2000000, seconds=30)`接受完整3–8个不同有理二维点，int64全局标签、256位int/Fraction坐标。拒bool、float、抽样、坐标重复及任意共线三元组。最小椭圆在共线三点上不能作为正定、正面积的已达到最优；本版本不自行约定其面积为0。原文平面域允许局部共线，所以这是明确的**受限实现域**，不是全篇完备性声明。

输出`EXACT_ELLIPSE_CODE`，完整面积代码、全部三角形几何及全部不同三元组间的有理比例。schema=`ellipse-image-code-2019-v1`，`domain_policy=every_triple_noncollinear`。几何椭圆使用中心c及shape矩阵S描述 `(x-c)^T S^-1 (x-c)≤1`；保留有理`area_squared_over_pi_squared=det(S)`，不把它称为面积或普通平方毫米。

每三角形顶点p_i的解析构造是项目推导：

    c = (p_1+p_2+p_3)/3
    S = (2/3) Σ_i (p_i-c)(p_i-c)^T
    det(S) = (4/27) D²,   D = twice_triangle_area.

故面积比的平方也等于det(S_num)/det(S_den)，正根由正面积比唯一确定。以等边三角形核算得共同常数 `4π/(3√3)`，该具体表达式是推导，原文只要求常数性。代码复用环境完整面积比核心，并用几何行列式再次交叉核验。

## 独立最小性证明

等权1/3的中心与协方差C满足S=2C，三顶点全在边界。对任意包含三顶点的椭圆(c',S')，正定S'下平均二次型≤1，因而

    tr(S'^-1 C) + (c-c')^T S'^-1(c-c') ≤ 1.

两个正特征值的算术几何均值不等式给出 `tr(S'^-1 C)≥2√(det(C)/det(S'))`，故`det(S')≥4det(C)=det(S)`。当前构造达到下界且包含凸三角形，是全局最小面积椭圆。验证器核对对称正定性、逆矩阵、中心/协方差等式、三接触点和行列式面积恒等式，不调用几何构造器或优化器。

`assess_ellipse_code2019(points, certificate, ...)`独立核全环境代码、精确输入、完整几何索引集和比例集，返回VERIFIED/INVALID/UNKNOWN。只有构造器返回EXACT状态后仍不足以替代独立验算。嵌套公开调用共享剩余工作/时间额度；协作式预算不是OS硬超时。超出域UNSUPPORTED；额度不足UNKNOWN，不判断不存在。

## 定理域

“任意三点非共线”与原文“非一条直线或两条平行直线”不是同一条件。平行四边形属于本几何构造域，但不属于原文平面图像定理域。结果另给`theorem_domain`，始终`affine_equivalence_decided=false`；一份代码不是两图代码等价或未知对应搜索的证据。
