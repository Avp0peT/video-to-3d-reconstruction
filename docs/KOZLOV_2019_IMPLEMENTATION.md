# 从2019论文思想到可核验代码

原文为S-2019-CODES，《Коды, определяющие изображения с точностью до аффинных преобразований》，打印57–60页。本轮已对照58/59页图像；[来源登记](sources/SOURCES.md)包含官方PDF与SHA256。本页解释实际实现思想，不把未知对应搜索、语义分割或照片重建算入这一篇的当前实现。

## 1. 图像的身份来自完整索引关系

原文把图像看成有限点集合，为点编号。对不同无序三元组t,u保存三角形面积比ρ(t,u)，分母面积为0则未定义。可逆仿射变换使所有面积同乘|det(H)|，所以比值不变。

不变的数值集合本身还不够：必须保留哪两组三点生成该数，以及比较两图时采用哪个一致的点编号双射。随意排序比值或只看直方图会丢掉约束，不能替代论文代码。

`coding/environment_code.py`构造完整环境S的代码，采用全局int64标签。A作为S的子图像时，只保留两组三元组标签全部属于A的项：这是真正从环境代码取限制，不将子图像点重新编号。环境中未选点也留在证书里，避免同一个标签在不同来源中被误认。

面积用双倍绝对行列式D表示，比例D_t/D_u用Fraction表示，正好等于面积比，无浮点误差。共线分子保留0，共线分母逐项登记为未定义；相同三元组的自对依原文排除。

## 2. 用环境的交叉比例检查给定对应

`coding/environment_proportionality.py`对显式A→B双射遍历A全部三元组。原文量化A中非退化三元组，并要求其面积除以B对应面积为共同常数；目标面积为0必须拒绝，不能跳过或倒零。源全共线时没有常数锚点，返回不支持，不作空量化通过。

实现分别输出：

- `paper_proportionality_given_mapping`：原文的单向比例谓词。
- `degeneracy_preserved`：全部三元组的零/非零模式是否保持。
- `full_area_proportionality`：前两者同时成立；明确为供工程消费的加强条件。
- `theorem_eligible`：原文谓词成立且两子图都满足论文的平面域。没有计算未知双射或构造仿射矩阵。

域外反例A={(0,0),(1,0),(2,0),(0,1)}，把中间点(1,0)对应到B的(1,1)：原文单向比例全是1，但原先共线三点变为不共线。代码必须保留“单向真、退化保持假、加强条件假、定理不适用”，而非只给一个成功布尔值。这不反驳原文限定平面域的定理。

A、B可以在同一环境内重叠。若一个三元组映射到自身，几何比例是1，但该自对不属于原文代码的索引集合；记录`SELF_PAIR_EXCLUDED`，不伪造“已在环境代码查到”的记录。负结果只否定给定双射；不证明其他双射不存在。

## 3. 椭圆代码为何可以精确计算

原文引理1：非退化三角形最小面积外接椭圆的面积，是该三角形面积的固定常数倍。这来自把三角形仿射化为等边三角形的思想。因此椭圆面积比仍等于三角形面积比，公共常数在比值中抵消。

`coding/ellipse_code2019.py`实现完整的带索引椭圆比值，并为每个三元组额外生成几何证书：中心、形状矩阵及其逆、面积平方/π²、接触权重。解析矩阵是项目推导；独立验证器以包含、重心/协方差、正定性与迹/行列式下界证明最小性，不依赖数值优化器，也不信任构造器的成功标志。

本版本明确要求每个三元组都不共线。共线三点没有正定正面积的已达到最小椭圆，不能偷偷用0面积假装实体存在。这个条件与原文的平面图像域不同：平行四边形无三点共线，却在两条平行直线上。因此几何可构造、代码可生成、定理可使用三者分开。

## 可执行范围

环境与比例性：完整1–8点环境，子集保持全局标签；椭圆代码：完整3–8点并满足严格三元组域。坐标为int/Fraction（256位界），拒绝bool/float/重复点；没有自动抽样。n=8完整给出56个三元组、3080个比例；椭圆另外给56个几何证书。

默认2,000,000工作量/30秒协作预算，嵌套构造和独立验证共用剩余额度。超限UNKNOWN，不宣称不存在。接口、给定样例、负例和独立验算分别有测试。

研究页面现有对应的显式运行入口；当前最终结果与复现命令见[本轮交付](../outputs/delegation/KOZLOV_LEGACY/20261014_environment_codes/HANDOFF.md)。合同分别为[环境子代码](contracts_environment_code_v1.md)、[给定对应比例性](contracts_environment_proportionality_v1.md)、[椭圆代码](contracts_ellipse_code2019_v1.md)。

这些是论文有限点集思想的代码实现。它们描述仿射等价下保留的结构，不自动恢复真实长度、透视深度、遮挡点或CAD实体；对真实图像的改善需要另做数据与对照实验。
