# 自动补充反向区域对应

完整自动入口（反向核验后，在存在可桥接的有效分量边界时自动加入真实中间关键帧）：

```powershell
& '<light-python>' -B -X utf8 scripts/refine_mask_region_model.py `
  --source-run '<completed-region-experiment>' `
  --source-geometry geometry02 `
  --run '<fresh-refinement-output>'
```

桥接策略为独立版本：在相邻有效分量变化、跨度不超过6个原端点时，选间隔1/3和2/3的实际视频帧，最多新增24帧。原64张图和SIFT行完整保留；新帧只追加空SIFT行并使用真实区域对应，绝不伪造描述子。原生上限仅在此策略下显式扩至96，默认流程仍64。新旧编号统一通过decode_index比较，并分列原始视图与新增视图，不能用分母变化虚报覆盖改善。

各阶段失败即保留证据并停止，不自动调参重试。下面单阶段入口仍可用于明确的独立实验。

现有区域实验完成后，可继续一次独立实验：

```powershell
& '<light-python>' -B -X utf8 scripts/improve_mask_regions.py execute `
  --source-run '<completed-region-experiment>' `
  --source-geometry geometry02 `
  --run '<fresh-output>'
```

`--source-geometry` 指定来源实验中的实际几何目录；若由新版单入口产生，通常为 `geometry`。支持先 `prepare`，再用相同 `--run` 执行 `run`。输出必须全新，失败保留证据，不自动改参数重试。

自动步骤：

1. 冻结来源图像/掩膜/原轨迹/数据库/模型和本次代码；生成原最大分量分裂ID纹理图册。
2. 保留全部原forward ID与坐标。从末帧向前连续跟踪，沿用21×21区域、原始纹理相关性、掩膜支持和正反向LK门槛。
3. 新反向候选在相邻原始关键帧之间另做直接双向匹配，与连续路径端点比较；两方向通过且位置差不超过2px才允许连接。UNKNOWN切段，不等同误匹配；孤立观测不进入本次新增对应。
4. 新反向段使用独立ID，不与原轨迹强制合并。复制原SIFT数据库，用同样原生参数重新几何验证和建模。
5. 对所有新旧分量重新检查相机域、注册视图、重投影、ID分裂和反向观测来源，输出比较页和每分量查看器。

上述反向单阶段只使用原关键帧进入SfM；完整入口的后续桥接阶段才增加SfM图像。每个跟踪/原生阶段600秒、4GiB Job提交量；OpenCV、BLAS与mapper配置为2线程。pycolmap 4.2.1的两视图验证接口未暴露线程参数，其内部线程池沿用后端默认，不声称整个进程最多2个OS线程。无GPU、无新依赖。诊断和评估各180秒。所有阶段由已有进程树监督器执行。

桥接输入需同步追加COLMAP的image、frame与rig关联，并把实际mapper图像选择集扩展到已绑定的新旧图像集合。评估再次核对实际选择集；未提交给mapper的新图不能记成“补帧仍无法注册”。

当前完整入口的顺序控制经过离线测试；反向、桥接和评估各子阶段已分别运行真实视频。完整入口尚未再做一次合并的原生重复运行，不借子阶段证据冒领该整条命令的端到端验收。

新增匹配、点数或注册视图不等于表面完整性、物理身份或CAD验收。不同方向可能观测到相同物理点，不能把新ID数当新物理点数。直接关键帧检查仅限制局部串接漂移，长轨迹身份、手套非刚体运动、掩膜误差仍需验证。随机几何验证沿用原配置，单次结果不构成严格因果结论。不自动拼接独立分量或填洞。
