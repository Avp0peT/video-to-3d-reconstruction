# 采集设备与视图术语更正

用户已明确当前使用的不是双目相机。当前照片/视频任务按普通相机的多视图重建解释，
不要求两台相机、双镜头同步采集或已知的固定硬件基线。

- **双目相机**：两路物理成像装置构成的硬件系统。
- **两视图计算**：从输入中选两张照片或两个视频帧进行几何计算；两张图可由同一台相机在不同时刻拍摄。
- **多视图重建**：使用多张有重叠、有合适视角变化的图像估计结构。
- **视图/照片 ID 与位姿**：此前报告中的“相机30/31”指第30/31个已注册图像对应的估计成像位姿，不是第30/31台物理相机。

此前“标定双目基线”“双目候选”“多次双目构造”等实验用语，应分别读作
“使用既有标定的两视图数值基线”“两视图候选”“多组两视图构造”。
这里数值基线是对照方法；几何基线是两个拍摄位置之间的距离，两者也不应混淆。
历史代码里的 `stereo` 名称不证明使用了双目硬件。

当前实验复用COLMAP估计的内参和逐图位姿。两视图恢复所用几何基线来自位姿中心之差，
没有因此获得已知物理长度；绝对尺度仍未知。
关于第30/31图的结论应表述为：当前标定估计的两个拍摄位置几乎重合，因此该视图组合的深度区分能力很弱。
相机估计本身尚无独立物理真值验证。

这份更正澄清硬件与数学视图的区别，不更改历史输入、坐标、证据、算法或验收状态。
后续面向用户的报告采用“两视图”和“单相机多视图”等准确称呼；涉及未知采集设备的输入不推断物理相机数量。

参考：[COLMAP的camera、image与rig术语](https://colmap.github.io/tutorial.html#terminology)。
