# Exact fixed orientation translation v1

Source bindings: S-2009 p102, Theorem 5 and the following characteristic-image/key-circle construction; S-2002 p258 minimum-circle translation reduction (PDF binding audited separately). The finite support enumeration is this project's implementation, not a complexity claim made by the author.

`solve_fixed_orientation_translation(source, target, mapping, *, orientation=None, max_work=2000000, seconds=30)` transforms source toward target. Both complete inputs are dictionaries of 1..32 distinct original 2D points. Labels are signed int64; coordinates and orientation entries are int/Fraction with numerator/denominator at most 256 bits; bool, float, duplicate original points, missing correspondence and nonorthogonal matrices are unsupported. Mapping is an explicit complete source-to-target bijection. Default Q is identity; exact Q-transpose-Q=I permits determinant +1 or -1. Reflection uses the same reduction but is an extension of the source's fixed-angle orientation-preserving family.

Let d_i=Q source_i-target_mapping(i). The characteristic kernel preserves every source label even when vectors coincide. If its minimum enclosing circle has center c and squared radius r2, the unique minimax translation is t=-c. Only r2 is returned: no approximate square root enters this API. Enumeration considers all 1/2/3-label circle supports, retains nonnegative barycentric weights, checks containment and selects the smallest exact r2. Worst-case arithmetic operation count is O(n4); rational bit complexity is not asserted constant. Candidate and stored certificate rationals are bounded at 16384 bits. Work accounting is cooperative and time is checked between bounded primitive operations, not a hard operating-system timeout.

The strict certificate contains exactly schema/source/target/mapping/orientation/kernel/center/translation/radius_squared/support/weights/residuals_squared. It includes complete normalized inputs and every paired squared residual. No bool, float, custom scalar, omitted/extra field or unbounded tree is accepted. Constructors return EXACT_OPTIMUM only after independent identities pass under the same remaining budget. UNKNOWN indicates budget exhaustion, UNSUPPORTED an input outside this bounded domain, INVALID an internal certificate failure. No certificate is returned as optimum on exhaustion.

`assess_fixed_orientation_certificate(source, target, mapping, certificate, *, orientation=None, max_work=2000000, seconds=30)` returns VERIFIED/INVALID/UNKNOWN/UNSUPPORTED. `verify_fixed_orientation_certificate(...)` is the convenience boolean and returns true only for VERIFIED. Assessment never invokes enumeration, support construction or the solver. It independently recalculates all kernel vectors and all transformed point errors, checks containment, support-boundary equality, nonnegative weights summing to one, and their weighted center identity. Supplied input is authoritative; embedded complete inputs must match it.

For any proposed center z, the support-weighted squared distance equals r2+||z-c||2, since the support-weighted vectors equal c. Thus the maximum squared distance is at least this quantity. Containment proves c achieves r2; the positive ||z-c||2 term proves uniqueness. This also handles zero radius and repeated kernel vectors without merging original points.

Scope: fixed correspondence and fixed rational orthogonal orientation only. This does not optimize correspondence, arbitrary angle, similarity scale, affine transformations, sketches, real camera geometry or reconstruction. Tests cover hand-derived supports, repeated kernels, rational rotations/reflections, complete pairing, independent no-search verification, malicious certificates, explicit domain boundaries and exhausted budgets.
