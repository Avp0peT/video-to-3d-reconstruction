# Environment proportionality under a supplied bijection

Source: S-2019-CODES p58, interpreted with this RUN's SOURCE_RULING.md. API `paper_proportionality_given_mapping(environment, source_labels, target_labels, mapping, *, max_work=2000000, seconds=30)`; `proportionality_given_mapping` is an alias with identical semantics. Complete environment uses environment_code's 1..8 distinct rational 2D points, signed int64 global labels and 256-bit numerator/denominator input bound. Explicit nonempty part-label subsets may overlap; mapping must be a complete bijection between them. No renumbering or unknown correspondence search occurs.

The paper's one-way predicate quantifies source's nonzero-area triples. Each target mapped triple must have positive area and source/target absolute area ratios must be the same positive rational constant. Doubled areas give identical ratios. Source with no nonzero triple returns UNSUPPORTED with no predicate certificate, never vacuous truth. Target-zero denominators are not inverted: their ledger ratio is UNDEFINED and reference TARGET_ZERO_DENOMINATOR. All source triples, including degenerate ones, remain in the ledger; source-zero rows are NOT_QUANTIFIED / SOURCE_DEGENERATE_NOT_QUANTIFIED.

Status PROPORTIONAL_GIVEN_MAPPING reports the one-way source predicate, NOT_PROPORTIONAL_GIVEN_MAPPING negates only this supplied correspondence. Separate exact booleans are paper_proportionality_given_mapping, degeneracy_preserved and full_area_proportionality. The latter is the stronger project-derived all-triple gate: the one-way predicate and matching zero/nonzero patterns. It must not be inferred solely from positive paper status. The documented domain-outside counterexample A=(0,0),(1,0),(2,0),(0,1), B=(0,0),(1,1),(2,0),(0,1) has paper predicate true but degeneracy and full gate false. It is not a counterexample to the plane-domain theorem.

The nested complete environment certificate is constructed by build_environment_code and independently verified through assess_environment_code. Each row stores source_triple/mapped_triple/pair/source_double_area/target_double_area/ratio/environment_ratio_reference. Positive different triples reference the actual global indexed source/target ratio. Coincident unordered triples instead record SELF_PAIR_EXCLUDED, with direct ratio 1: the pair is absent from environment code by definition and must never be fabricated. A=B with identity correspondence is supported by direct witnesses even when the environment ratio table is empty.

source_domain and target_domain separately classify collinear/two_parallel_lines/plane. theorem_eligible is true only for a positive paper predicate and both actual plane domains; it is not a supplied affine witness. No matrix is constructed and unknown_mapping_decided is false. Stronger full_area_proportionality is preserved separately even in that case; no geometric correspondence certification is silently asserted.

The strict certificate preserves complete raw normalized environment bindings, both global part-label subsets, exact mapping, complete triple ledger, constant, domains and verdict. The field constant is the first defined positive source/target reference ratio; it is a candidate/reference value on negative results and a common constant only on positive results. If every source-nonzero triple maps to zero, it is the explicit NO_POSITIVE_RATIO sentinel. assess_proportionality_certificate(environment, source_labels, target_labels, mapping, certificate, *, max_work=2000000, seconds=30) never invokes constructors or the ledger builder. It recomputes every required triple using expanded determinants, independently verifies the nested environment, checks all indexed lookups/self exclusions, ratio constant, degeneracy, domain and verdict. Strict typed equality rejects bool masquerading as rationals or labels. UNKNOWN is budget exhaustion, INVALID denotes invalid supplied certificates; constructor UNSUPPORTED is unsupported input/no anchor. All nested construction and verification use one cooperative 2M-work/30-second ceiling; no partial certificate is labelled complete.

Scope is definition-level exact finite predicate and stronger metadata, not unknown-bijection recognition, affine-matrix recovery, ellipse construction or production photo/CAD execution.
