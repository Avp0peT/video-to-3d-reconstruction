# indexed-body-code-v1 — 有界精确三维索引代码

来源是来源表 S-1996（PDF p.6/7，期刊325/326），本轮已目视核对。原文定义有限三维点集、互异编号、无序四元组、不同四元组间的非负体积比，零分母未定义；共面全体不在代码定义域。四元组可相交，零分子保留。定理3另有限制：点集不能包含在一平面或两平行平面的并集中。以下类型、界限和算法是这些定义的软件表示，不是作者命名的 AlgT'/AlgSo。

令 Q 为全部四元组，D 为精确体积非零者，完整代码为标签集合与所有 `(p,q,Vp/Vq)`，其中 p∈Q、q∈D、p≠q。实际记录数为 `len(D)*(len(Q)-1)`；相同比值若索引不同必须分别保留。不按值去重、不量化、不补自身比值。不共面4点的合法代码记录为空；这与全体共面时代码未定义不同。

## API 与限制

新模块 `kozlov_lab.stereo.official.indexed_code3d`，不替换旧 `kozlov_body_code` 数值摘要或 `is_a_equivalent` 几何 oracle。

- `indexed_body_code(points, labels=None, max_entries=10000)` 返回不可变 `IndexedBodyCode`。默认标签0..n-1，显式标签为互异有符号64位整数。输入1..12个不同三维点，坐标接受整数、Fraction及有限的至多binary64浮点；逐标量直接转Fraction，不先经NumPy/PointSet3D。浮点层表示实际存储值，不表示原测量是真值。每坐标分子/分母各≤2048bit，拒bool/string/complex/Decimal、重复点、错误形状与超限，抛 `CodeInputError`/`CodeBudgetError`。不会静默去重或改变标签。
- 精确绝对行列式计算6V，体积比中6相消。完整记录预算为1..250000；实际需要量在创建记录前检查，超限抛 `CodeBudgetError`，没有冒称完整的截断对象。
- 状态 `DEFINED` 或 `UNDEFINED_PLANAR`。前者 `complete=true` 且记录全部物化；后者仍保留标签/点和四元组零表、没有合法代码，不可用空记录比较成等价。
- `code_equivalence_for_mapping(left,right,mapping)` 验证显式全局标签双射，所有索引及比值用同一映射。参数不合法抛错误；未定义代码返回 `UNKNOWN`。结果为 `EQUIVALENT/NOT_EQUIVALENT/UNKNOWN`、equivalent=true/false/null、理由及逐标签见证。`comparison_scope=supplied_bijection`；false仅否定所给映射，不能据此说不存在别的双射。
- `find_code_equivalence(left,right,max_permutations=10000)` 对最多8点按输入标签次序确定性枚举全局双射；预算1..100000，9–12点调用抛CodeBudgetError，可改为验证给定映射。`comparison_scope=existential_bijection`：找到见证即已证明存在，无需枚举剩余排列；标签/索引域数量等必要条件不符可直接否定，否则穷尽全部排列才证明不存在；预算耗尽是 `UNKNOWN`。`search_exhausted`仅表示确实穷尽枚举，必要条件拒绝时为false。完整代码与完整搜索是两个字段，不混用。`permutation[i]` 表示左对象第i个标签对应右对象第几行。
- 搜索以完整四元组表的比例关系检验对应；若一个非零参照分母成立并对全部四元组交叉相乘相等，则所有不同索引比值相等，反向也成立（单四元组空记录边界单列）。这是一种精确因子化验证，不是排序值摘要或坐标拟合。显式 mapping 验证另逐条核对物化记录及有定义域，作为独立的最终见证核验。

序列化采用 `rational-hex-v1`：每个有理数字段是 numerator_hex/denominator_hex（Python hex格式，分母正），避免极端但合法的整数触发十进制转换长度限制；用 `Fraction(int(n,16),int(d,16))` 还原。代码摘要/JSON hash只识别当前编号呈现，绝不是重编号不变量。

公开对象仅由工厂创建，禁止直接构造及dataclasses.replace；内部域见证递归冻结，避免删去记录或改写域后仍保留complete状态。显式mapping参数先验证，即使代码未定义亦不会吞掉无效参数。故意绕过Python对象保护或私有工厂不属于支持的API。

## 定理域检查与结论边界

本项目附加精确有限检查：对非共面集枚举全部点对差向量的两两叉积，以每个非零法向量检查所有点的投影是否最多两种。若存在则记录法向量、两偏移值及标签分组，标记不属于定理3的体积图像域。若全部候选均否，则属于该域。其完备性依据：若满仿射秩3的点集可分成两平行平面，两个组内差向量合计必须张成二维；秩≤1会令全体秩≤2，秩3则不可能存在共同法向量。因此其中两个独立组内点对差一定被枚举，其叉积给出所求法向量。此有限检测算法是本项目推导，不冠以原文算法名。

即使域已核对，本API仍只报告代码定义式等价，不自动输出仿射等价结论，也不重建坐标。调用旧浮点几何oracle必须单列证据。全体共面或搜索预算耗尽不能升级为否定。代码等价不是实际尺度、欧氏刚性形状、视角对应、照片重建质量或 CAD 有效性的证明。

资源：点数、坐标位数、记录数及排列数均有硬计数上限；它们不是墙钟/进程树内存看守，实际任务另设外层。当前小规模完整代码不能用于整个2393点云；真实点子集演示必须保留选择规则及范围，不称全模型验收。

现有历史报告保留原字节，在当前使用说明/规格中连接勘误；仅修正当前UI、实验脚本输出和函数说明中的错误能力名称，不重写历史运行结论。
