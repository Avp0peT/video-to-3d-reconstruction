1. 核心结果：内部仿射坐标的仿射不变性

取图像三个不共线点 A, B, C，则任意点 P 有唯一分解 P − A = α(B − A) + β(C − A)。对任意可逆仿射变换 T(x) = Mx + t， (α, β) 不变（标架随图像一起变换）。这就是可以充当图像编码的不变量。

为什么这个数字可信：它同时满足三条独立检查 —— ① 1000 次随机变换的最大值（不是单次样本）； ② 与理论界 cond·ε·64 逐行比较（不是"恰好低于阈值"）； ③ 可证伪性：同样的实验在病态标架上必须超过 1e-9，实测 1.35e-8 —— 证明这个阈值具有区分力，而不是自证成立。

E2：平移幅度是独立失效模式

平移在线性部分是恒等映射，直觉上不该影响内部坐标。数值上它影响很大， 因为坐标量级决定其可分辨精度，而 α 要除以标架尺寸：

max|Δα| ≈ ulp(max|coordinate|) / |B − A|  =  ε·|t| / |B − A|
|t|预测实测实测/预测
11.110e-161.110e-161.00
1e31.110e-136.151e-140.55
1e61.110e-106.306e-110.57

信息在输入阶段（坐标被舍入）就丢了，求解器无法恢复，故条件数界看不到它。 尺度 × 平移共 15 组配置中，实测/预测最大比值 ≈ 2.2， 另有 3 组误差塌到 1e-16（小型点集上舍入恰好完全抵消）—— 所以这类误差必须用多配置最大值报告，引用单次样本会得到假的好结果。

第 3 项的完整反例

a = (0, 0),  b = (3.47370303e-152, 0),  c = (0, 1)

|sin(∠BAC)| = 1.0                      ← 在顶点 A
|sin(∠BCA)| = 3.5e-152                 ← 在顶点 C

同一组点，用 |sin(∠BAC)| > 1e-9 判「是否共线」→ 换名后结论相反。

修法：用 flatness = 2·Area / max_side² = h_min / max_side（置换不变）。 注意两者都保留：顶点正弦用于诊断「这个标架」的条件数（其含义本就依赖顶点）， flatness 用于定义「关系」。这不是「哪个更好」的问题。

6.4 ⚠️ 同一轮发现的实现级事实

字面执行源定义的分母判据 S != 0 在浮点下不可用。 实测（数据集 B）：

量值
最小非零面积（纯舍入）1.11e-16
最大面积3.41
因此 max ρ3.07e+16
一次纯平移后 max ρ1.23e+17

即 T_A 的最大元素由无数学内容的舍入决定，且在平移下改变—— 用这种 T_A 做判定，会把「同一图像平移一下」判成不同代码。 改用无量纲的 flatness 判据后，5 数据集 × 8 族全部通过（9.5e-14）。

同样的教训在 Phase 2 出现过一次：有量纲的量 × 固定阈值必然出错。

6.5 另外两个被修掉的坑

  • 比较度量选错会制造假的失败：第一版用「相对该值」的偏差，报出 1e283。 真因是分母塌陷（ρ=0 平移后变成 ~1e-283）。改为相对集合尺度，并把近零元素数报告出来。
  • 两处退化判据必须一致：全码与截短码用不同判据时，截短码在 B 上偏差 0.25 而全码通过。
