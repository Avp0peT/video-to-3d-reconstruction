## 0. 一句话开场（30 秒）

> 同一个东西，移动一下，坐标就全变了。
> 所以坐标清单不是它的"描述"。
> 我们想知道的是：**什么样的量才能算作视觉对象的描述？**

## 1. 演示脚本（可现场运行）

```bash
python experiments/mvp_walkthrough.py
```

输出覆盖 README 第 25 节第 1–7 步，逐步如下。

### ① 创建一个 ≥5 点的图形

用 `square_3x`（12 点）：既是教材式的简单图形，
又包含共线三元组与平行线段，从而让后面的不变量表**有见证**（不是空表）。

> 讲解点：为什么不用 4 个角的正方形？因为 4 个角里没有三个共线点，
> 后面"共线性保持"那一行会变成"无见证"——技术上通过，但没有说明力。
> 这个选择本身就是一次方法学决策。

### ② 生成随机可逆仿射变换

$A$ 由奇异值构造，$\mathrm{cond}(A)\le20$，$\det A\neq0$。

> 讲解点：为什么限制条件数？因为条件数决定后面误差的可达下界。
> 不限条件数的话，"误差很小"会变成一个关于运气的结果。

### ③④ 外部坐标全部改变

演示：$\max_i\|x_i-x'_i\|=7.86$（图像本身尺度只有 2）。

> 这是第一处"反直觉但显然"：视觉上还是同一个正方形，
> 但坐标**逐位全不相同**。

### ⑤ 选择三个不共线参考点

`AffineFrame.auto` 选择使 $\mathrm{cond}/\mathrm{flatness}$ 最小的三元组。
本例自动选中 $(0,3,9)=(0,0),(2,0),(0,2)$，$\mathrm{cond}=1.00$（理论最优）。

> 讲解点：为什么不能随便选三个点？
> 因为 $\mathrm{cond}$ 完全由"选哪三个点"决定，它决定了后面全部数值精度。
> 界面同时显示 `flatness` 与 `cond`，而不是只显示"合法/非法"。

**「为什么？」面板（README 第 21 节）**：

> **为什么要求三个点不共线？**
> 因为 $B-A$ 与 $C-A$ 必须线性无关，否则不能形成二维仿射坐标系。
> 形式化地：$\det[B-A,\ C-A]\neq0$。

### ⑥ 计算所有点的内部坐标

逐点打印「外部坐标 → 内部坐标」两列，并给出一行公式：

```text
P - A = 0.500 (B - A) + 0.250 (C - A)
```

只有数值是不够的（README 第 20 节明确要求图形 + 公式 + 数值 + 解释）：

> 点 $P$ 的位置可以完全由它相对于 $A$、$B$、$C$ 的关系描述。
>
> Положение точки $P$ задаётся её внутренними аффинными координатами
> относительно $A$, $B$ и $C$.

### ⑦ 数值上证明不变

实测（本机，2026-10-01）：

```text
max |alpha - alpha'| = 2.220e-16
max |beta  - beta' | = 2.220e-16
要求 < 1e-9           : 通过
可达精度界            = 4.789e-14
最大残差              = 4.441e-16
```

> **这是全场最重要的一屏。**
> ①–④ 坐标全变；⑦ 内部坐标只差 $2.2\times10^{-16}$（机器精度）。
>
> 但要主动补充一句（否则会被误读）：
> 这个 $10^{-9}$ 是**良态标架**的结论；标架越扁，可达精度越低，
> 库里会直接报告可达精度（见 `docs/theory/numerical_limits.md`）。

### ⑧–⑩ 图像代码与等价判定

**明确说明本阶段不做**，并说明原因（Phase 3 Gate + 未决问题 Q1）。

> 这一处**必须**停在诚实的位置：
> 演示里不提供占位实现，也不把哈希说成"图像代码"。
> 预判提问："那你怎么知道这套东西能用来识别？"
> 回答：⑥⑦ 已经证明了识别所需的**唯一数学前提**成立——
> 存在一个对仿射变换不变的编码量。
> 至于"如何把它变成可比较的代码"，正是下一步（Phase 3）要按教材定义解决的问题。

## 2. 现场问答预案

| 提问 | 回答要点 |
|---|---|
| 这不就是归一化坐标吗？ | 是，但关键差别在**归一化用什么基准**：这里是图像**自身的三个点**，不是外部坐标轴；因此基准随图像一起被变换，比值才严格不变。 |
| 用哈希做代码不就行了？ | 哈希是**索引**不是数学代码。坐标上 $10^{-16}$ 的扰动会让哈希完全改变，而数学上两图几乎相同。哈希无法回答"差多少"。 |
| 为什么不用神经网络？ | 本项目评价的不是"识别现实图片有多准"，而是"是否把教材的数学思想正确转成了可观察、可实验的算法"（README 第 23 节）。CNN 会把要展示的机制藏起来。 |
| 不变量真的不乱吗？ | 请现场看 `results/M6-INVARIANT-TABLE_2026-10-01/`：表格里每一项都有实测偏差与见证；控制组（无关图像）7 项全部被破坏。 |
| 为什么共线性/平行性行永远是"保持"？ | 因为它们是**关系**，仿射变换确实保持关系；表格用对称差检验，控制组显示该检验能报错。 |
| 误差怎么保证不是碰巧？ | ① 1000 次随机变换的最大值；② 与理论界 $\mathrm{cond}\cdot\varepsilon\cdot64$ 比较；③ 病态标架下**必须**超过 $10^{-9}$（可证伪性检查）。 |
