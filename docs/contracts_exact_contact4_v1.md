# 完整输入四接触精确椭圆与实代数域 v1

2026-10-13；S-2025 PDF4 / 期刊149的最小面积外接椭圆中心定义。本实现的代数推导与独立最优性证明是项目推导，不把源码当作原文算法。

`exact_contact4_ellipse.complete_input_contact4_ellipse`接收完整1–7个互异二维有理点、整数标签；拒bool和float，不抽样。四个接触点只作支撑证书，不替代完整输入。以支撑均值为原点的二次曲线固定常数项−1，四个边界方程构成有理单参数pencil。令K=AC−B²、J=CD²−2BDE+AE²、U=J+K，面积平方驻点满足 `2U'K−3UK'=0`，次数至多三。枚举实根并验证正定、全部输入包含与严格正接触权重。

`real_algebraic`用有理Sturm隔离实根，`Root`包含平方自由次数1–3的多项式和恰含一根的有理开区间；`AN`为该指定根上的有理函数。可约多项式按指定根检查分母，不误将整个商环当作域。互素分母用模逆归一化；其他分母保留根局部语义。四则、符号和相等均不转浮点。不同Root对象不能直接运算，未实现一般复合域。

存储有理数16384位、算术多项式最多13系数、隔离/符号细分最多4096步；另有共享work与monotonic时间预算。位数门作用于受检存储结果，不声称Python每个临时整数都有硬上限。工作预算是合作式操作计量，非OS抢占。超限UNKNOWN，不作不存在结论。

独立`exact_contact4_verify.assess_contact4_certificate`不调用候选构造、RREF、pencil、凸包或根枚举。它重查完整输入摘要与标签、Root、正定S/H及SH=I、正权重和为1、加权中心、协方差=S/2、支撑边界与全部点包含、面积与长轴公式。正权重协方差给出全体外接椭圆的面积下界；候选达到下界，证明最优。驻点或构造记录不是验收权威。

证书数值为原生严格整数对；中心、形状、权重和距离带统一Root语境。统一入口`exact_center.solve_exact_center`在同一预算内尝试点/线、三角凸包、contact3、contact5、contact4，配独立`assess_exact_center_result`和无损JSON codec。点/线状态为`EXACT_DEGENERATE_COMPLETE_INPUT`，不称非退化正定椭圆。浮点、bool污染、漏完整输入、篡改root/面积/权重须拒绝。

这关闭有限输入上一般四接触候选缺项；并未完成一般尺寸比较、通用fits、三维扩展、照片匹配或研究总验收。
