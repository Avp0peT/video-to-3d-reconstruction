# 自动选视图与几何诊断

照片和视频入口现在默认在可用 SfM 之后附加 `view_geometry` 诊断侧支。
这里的两视图来自已注册图像，不要求双目硬件，也不推断采集设备数量。
原生模型、特征对应、掩膜和旧报告保持原样；后续表面和 CAD 继续使用原生模型。
这一步是工程几何检查，未调用或替换 Kozlov 的 AlgT′/AlgS0。

## 实际执行

`scripts/run_photo_demo.py plan|run` 默认 `--view-geometry-audit`，可用
`--no-view-geometry-audit` 显式关闭。`report` 仅重绘并核验已有报告，不运行诊断；
既有 `resume`/`continue-cad` 也不会补跑这一新侧支。

独立检查已有数据：

```powershell
python -B -X utf8 scripts/audit_view_geometry.py --sfm-run '<原生运行目录>' --model-id '0' --output '<全新目录>'
```

统一入口使用现有监督器：90 秒、1 GiB 提交内存、2 线程、一次执行。
取消、超时或回收未确认会停止后续重型阶段；普通数值诊断失败单独记为 FAILED，
保留原模型和后续几何成果。诊断完成状态不参与模型 SUCCESS 的判定。
独立 CLI 有60秒软计算期限，使用者应在外层限制90秒；解析阶段也受统一入口的外限保护。

## 固定策略与覆盖范围

1. 按既有规则选择一个可用 SfM 分量，或使用显式 model_id；不拼接分量。
2. 读取原生轨迹的特征坐标、估计内参和逐图位姿。原生 XYZ 只经文件格式合法性校验，
   不用于选图、初始化、拟合或评分。
3. 分析 point_id 排序的前256条轨迹，PLAN 同时列出其余未分析的全部 ID。
   每条要求2至64个无歧义视图；不满足时保留原因，不换一条轨迹补数。
4. 去畸变后将视线转换到世界坐标，以视线夹角的正弦排序，分数相同时按图像 ID。
   近0°与近180°都弱；用相对拍摄中心间距排除数值重合。这里没有物理尺度门槛。
5. 只用所选两图的原始观测做 DLT 和有界 XYZ 优化，固定所有相机。
   同时保留“编号最小两图”的对照；编号不等于时间顺序。
6. 回投影核对全部提供的观测，包括拟合用的两图。逐视图保留失败和残差；
   任一视图失败时整体不报告通过。歧义视图保留位置记录，阻止声称完整覆盖。

`TRACKS.json` 保存所有抽样槽、原始观测、完整选对排序、所选候选、对照和逐视图残差。
`RESULT.json` 的源绑定是 run.json 及选定分量的三个原生 binary 文件；
报告发布前验证 RESULT、PLAN、TRACKS、HTML 与这些源文件的字节身份。

## 结论边界

- 选图可能选中视角差异很大的错误匹配；排序不是正确性判断。
- 其余视图已参与选图和历史相机估计，不是独立验证集。
- `OBSERVATION_INCONSISTENCY_DETECTED` 表示所有观测中存在超过既有2 px诊断线的残差。
- `WITHIN_DIAGNOSTIC_LINE_NOT_VERIFIED` 只表示未超过该线；`PAIR_ONLY_NOT_VERIFIED`
  明确没有第三视图。两者都不是精度或匹配验收。
- 候选投影失败、重复观测歧义、视图上限和未抽样轨迹均单独保留。
- 选图模块的相对判据与既有拟合器的绝对数值界限不同；未知尺度极端时
  `FIT_REFUSED` 可能来自数值支持域，不能直接解释为物理退化。
- 不自动删点、修改图像、填洞或重新启动 SfM；物理尺度、前景质量和 CAD 验收仍单独处理。
