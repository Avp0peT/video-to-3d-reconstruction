# 单物体先分割再选点

公共照片/视频入口默认顺序为：输入准备 → SAM3 → 前景 SfM → 几何检查 → 表面/Blender/CAD（按原有条件）。物体描述指定本次目标实例类别，多候选仍需明确选择；不按面积或分数擅自选择。

已有同一 T01 输入的正式 SAM3 清单可以单独接入：

```powershell
& '<原生Python>' -B -X utf8 scripts/reconstruct_object.py --io-run '<原T01目录>' --object-mask-manifest '<正式manifest.json>' --output '<项目outputs/delegation/T02A下的新目录>'
```

CLI 不传该参数仍保留显式整图研究用途；公共单物体产线总是传入此参数，分割缺失时停止。

`foreground/FOREGROUND_SELECTION_LEDGER.json` 绑定原图、T01、SAM3清单和候选字节；全部原始输入行保留。仅已选中非空 `OK` mask 参与，其他行以 `EXCLUDED_FOREGROUND` 保留在 frames_map，原分割原因保留在选择账本。不得用新增未识别帧补充背景特征。

RGB 原图不涂黑、不裁剪、不重采样；`ImageReaderOptions.mask_path` 指向分离的二值掩膜树。mask 文件采用 COLMAP 的 `image_name + .png` 命名。数据库回查遵循冻结 COLMAP 4.2.1 的像素坐标截断规则。`foreground.mask_consumption_verified=true` 仅在原生 reader 配置及全部数据库特征中心通过回查时出现。

这是特征**中心**的区域约束，并不保证 SIFT 描述子邻域完全落在目标内，也不证明每个匹配或三维点正确。分割孔洞保留；不把掩膜当人工真值。反光、重复纹理、缺少纹理或视角、标定误差和错误对应仍可能造成分裂或失真。

本次改动不把 Kozlov 的精确平行投影构造替换成分割算法；识别目标提供允许选点区域，跨视对应与三维恢复分别验证。

## 从已有视频产物自动优化选点

当目标内特征集中、仅有少量照片注册时，可运行新的独立比较入口；不需要重拍，也不重新运行 SAM3：

```powershell
& '<原生Python>' -B -X utf8 scripts/optimize_object_points.py run --pipeline '<已有视频pipeline目录>' --output '<全新结果目录>'
```

入口自动核对视频、图像、原 SAM 清单与 SIFT 数据库，按原解码配置读出全部视频帧；复核原采样帧像素一致后，对同一组图像运行 SIFT 种子连续跟踪和物体分区种子连续跟踪。分区方案在目标 bbox 的 8×8 格中检测真实角点，每格最多12条、全局最多768条；点随图像运动，采样时按当前位置重排配额并补充缺点区域。它不是向网格中心填入虚构对应点。

两组共用逐原帧 LK、前后向误差与局部亮度归一化相关检查。只有已有有效 SAM 的采样帧产生可入库的观测；中间帧仅连接轨迹，未知目标区域不宣称前景，原采样 NO_MATCH 会断开轨迹。候选轨迹在至少3个有效采样帧出现后，才进入独立 COLMAP 数据库做原生两视图验证和重建。这是候选准入条件，不保证最终三维点有3视图支持。

`index.html` 自动提供逐帧三列、四阶段对照；`SUMMARY.json` 记录4/8/12网格覆盖敏感性，`RESULT.json` 记录进程回收与输入漂移。各个 native 目录保存独立模型的 binary/text/PLY。不同模型的坐标不能直接拼接；图像占格率不是三维表面覆盖率，也不证明对应正确。`COMPARISON_COMPLETE` 只表示比较执行完成；几何质量仍另行验收。

此入口是已有产物上的可重复自动续跑命令，尚未作为公共 `run_photo_demo` 的默认回退。当前版本固定2线程、每组原生240秒、进程树提交量8 GiB、输出2 GiB；不覆盖既有输出。两视图内部RANSAC按固定版本限制使用1线程。边界侵蚀7像素只约束采样端点的15×15相关块，不能保证光流金字塔在所有中间帧的支持域都位于目标内。

### 允许短暂失联后的实测恢复

在上面的比较完成后，可自动复用同一视频解码字节运行恢复方案：

```powershell
& '<原生Python>' -B -X utf8 scripts/recover_object_tracks.py run --control '<optimize_object_points已完成结果目录>' --output '<全新恢复结果目录>'
```

此命令冻结原输入、全部已解码帧和旧实现，自动执行恢复跟踪、同一原生几何消费器、逐帧对照报告。它不重新分割、解码、拍摄，也不修改原连续跟踪结果。原生消费器的 `arm=balanced` 表示未变的分区种子方法；轨迹的 `tracking_variant=gap_tolerant_v1` 标识新跟踪方式。

原单步检查失败后，ID进入pending，距上次真实测量最多3个原始视频帧内尝试恢复（因此最多缺失2帧后在第3帧认回）。至少6个仍有真实对应的邻居支持局部相似运动，最终内点需二维展开并支持待恢复位置。当前图像被变换到参考局部坐标后搜索模板，正反搜索均检查相关性和第二峰歧义；同帧恢复碰撞不合并ID。只在真实图像支持后恢复原ID，缺失帧不插值、不累计采样数。暂失但没有当前测量的位置不会显示为成功点。

真实SAM采样边界先过滤再保存测量；有效mask不会仅因pending没有当前位置就删除其身份，但该帧不写它的观测。`NO_MATCH`仍明确结束全部轨迹，不伪造物体区域。`recovered`表示此ID在当前采样或之前经历过实测恢复；`recovered_this_decode`才表示本原视频帧刚恢复。

结果中的 `COMPARISON_COMPLETE`仍只代表执行完成。恢复身份不是独立物理真值；候选增加、占格增加、注册增加需分别统计。输出包含逐原帧 `steps.jsonl`、恢复事件 `recovery_events.jsonl`、真实采样观测和双列四阶段报告。当前自动续跑未改为公共建模入口默认策略。预算为2线程、跟踪390秒、原生240秒、提交量8 GiB、输出1 GiB，原生失败或有界回收未确认即停。
