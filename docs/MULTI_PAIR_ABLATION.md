# 多照片对的 Kozlov 构造消融实验

本入口扩展上一轮六点工程桥，目的是查清 AlgT′ 在已有标定和对应条件下提供的能力。它不是完整多视图重建/融合，也不替代 COLMAP 标定、匹配或 MVS。

```powershell
python -B -X utf8 scripts/experiment_multi_pair.py --prior-input '<旧精确适用性诊断>\INPUT.json' --output '<新目录>'
```

## 冻结范围

- 保留此前参考照片对。按共同唯一 track 数降序、图像 ID 升序，贪心选择最多另两对，要求三个 pair 不共享图像。
- 每对按 track ID 升序分为完整连续六点块。最多40块；超限时取 `floor(k*(n-1)/39)`，含首尾。未取整块与不足六点的尾部全部记录，不能改组补足。
- 同一 scene、相同旧标定、可能相同 track：**图像互斥不等于独立数据集**。高共同点数选择偏向 COLMAP 已经成功重建、覆盖充分的输入。
- 每组都执行正常对照及固定右侧原像素循环移位一位的负控制。右来源 track ID 单列，不按结果更换负控制。负控制坐标绝不导出为模型。
- 配置、图像字节、相机与姿态、完整候选 pair 排名及 block 清单先写 `PLAN.json`，随后才计算。

## 三条路径

| 路径 | 输入处理 | 输出意义 |
|---|---|---|
| A | 去畸变、共同旋转校正、两图y均值，不量化 | 标定双目数值基线 |
| B | 同A，增加固定18bit有理量化 | 与C完全相同输入的数值基线 |
| C | 同B的输入，实际AlgT′两视构造、JSON往返、独立证书核验、由证书body两投影复原像素、反视差恢复 | 精确代表和几何证据，再经过相同工程变换 |

A/B差异反映固定量化影响；B/C预期相等。若一致，不称精度提升：C的新增产物是可核验的构造见证。若不一致，应检查实现或序列化，不能解释成算法发现更优三维。

共同y使每个联合观测落在 `(xL,y,xR)` 三参数空间，低维条件是预处理施加的。错配也可能经此变成可构造代理，故**代理证书不能当原始匹配正确性的判据**。原像素变化、纵坐标差、证书、正视差、世界转换及原相机回投影分开记录。

状态分层：原生构造结果立即保存 `C.exact_status`；独立核验、投影读回与world转换的失败不会覆盖它，也不会借用B结果。所有失败都留在requested分母中。原相机数值闭环门是1e-7像素，照片质量阈值仍未定义。

## 输出

- `groups/`：每个正常/负控的完整输入、来源ID、A/B/C、量化及exact_result。
- `RESULT.json`：每pair与全局分母、各阶段状态、A/B/C差异；故意错配可构造数单列。
- `CANDIDATE_SAMPLES.json` / `candidate_samples.ply`：仅正常组且数值闭环通过的C坐标；重复track按pair分别保留，不平均、不融合，无面，前景未认证。
- `CROSS_PAIR.json`：同track跨不同pair的坐标差。不再配准、不当真值。
- `report.html`：可查看报告。

旧XYZ只在候选计算结束后用于数值对照；此前原生解析器已消费二进制记录但丢弃XYZ，不能声称此前未读取那些字节。所有单位沿旧COLMAP任意尺度。既有标定与对应也是全部结果的依赖。

## 多图、视频与双目的关系

完整物体仍以多视图 SfM/MVS 为主：更多合适视角可提供覆盖和额外约束；视频需要选择清晰且有视角差异的关键帧。多次双目独立计算之后，仍需跨视图身份、全局优化和表面融合，不能直接把点集合并叫完整重建。

官方参考：[COLMAP采集与SfM/MVS流程](https://colmap.github.io/tutorial.html)、[Meshroom关键帧选择](https://meshroom-manual.readthedocs.io/en/bibtex1/node-reference/nodes/KeyframeSelection.html)。前者建议重叠且不同位置的图像、视频降采样；后者说明去除过相似和模糊帧。本文不依据旧版文档声称当前GUI操作细节。
