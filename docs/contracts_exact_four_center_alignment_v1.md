# exact-four-center-alignment-v1

This is a complete global minimax centre-alignment branch for exactly four distinct rational source centres, every source triple noncollinear, and four distinct rational target centres of affine rank two. It does not establish whole-block containment, futlyar conditions, or original local fits. Labels are 64-bit integers; coordinates int/Fraction with 256-bit reduced numerator/denominator; bool and floats are rejected. All inputs and all 24 bijections are preserved.

For source y, the signed minors of the columns (1,y_x,y_y), normalized to c_0=1, give the unique affine relation sum c_i=0, sum c_i y_i=0. Every c_i is nonzero. For each permutation pi put S=sum |c_i| and v_pi=-sum c_i x_pi(i)/S. Every affine residual r_i=T(y_i)-x_pi(i) satisfies sum c_i r_i=S v_pi, hence max ||r_i|| >= ||v_pi||. Set r_i=sign(c_i)v_pi. The relation guarantees all four desired images are affine-consistent; the first three determine a unique matrix/translation. This matrix, including singular candidates, achieves the unrestricted affine lower bound. The full 24-entry ledger gives the global lower bound by the minimum squared norm.

Invertible affine maps are dense: add rational delta*I to a singular linear part, avoiding finitely many roots of its determinant; residuals converge. Thus the minimum over the ledger is always the infimum over invertible maps. If some globally minimal candidate is invertible it attains the global optimum. Otherwise the infimum is unattained: equality in the Euclidean triangle bound, with every |c_i| positive, forces precisely these four residuals (including the zero-error case). No other invertible attaining map exists. GLOBAL_INFIMUM_UNATTAINED reports this explicitly.

Strong common-affine stability is certified only when an attaining minimum exists and every minimum vector equals plus or minus the selected vector. Under common invertible H on both configurations the relation is unchanged, all vectors become H v, and these ties persist. For each higher energy E_j and selected E, define gap=E_j-E. The rational epsilon is min(1/4, all gap/[8(E_j+E)]), with epsilon=1/4 when no higher candidate exists. Elementwise |H_ab-I_ab|<epsilon implies ||H-I||_2<=2epsilon. Therefore | ||Hv||²-||v||² | <=(4epsilon+4epsilon²)||v||² <=5epsilon||v||², and each higher-versus-chosen gap remains positive since 5epsilon(E_j+E)<=5gap/8. Translation cancels. The original attaining transformation is conjugated by the common affine H and remains invertible. GLOBAL_OPTIMAL_STABLE certifies this stronger global persistence. GLOBAL_OPTIMAL_STABILITY_UNRESOLVED means tied nonparallel minimum directions; it does not deny local stability or original fits. The certificate `epsilon` bounds common H matrix entries. The original definition instead bounds point displacement on X union B0, so the certificate also provides the exact bridge `epsilon_point_displacement`. Select the first noncollinear target triple in canonical label order, form D with columns x_b-x_a and x_c-x_a, and put K=max_j sum_i |(D^-1)_ij|>0. If each point displacement norm is less than delta, each entry of E=(H-I)D is less than 2delta, because the common affine translation cancels on differences. Each entry of H-I=E D^-1 is then less than 2delta K. Set delta=epsilon/[4 max(1,K)]; this implies the required matrix-entry bound with margin. The verifier recomputes this exact inverse formula and radius from the complete target. Stable classifications have positive delta; other classifications have zero delta and make no stability claim. `epsilon1=Fraction(1)` is a fixed positive source-transformation local radius: the global result implies the requested local result throughout that same radius before and after every qualifying common perturbation. Thus the same epsilon1 is retained independently of H.

`align_four_centers(target,source)` returns a typed exact dictionary certificate, classification and work_used. `assess_four_center_alignment_certificate` independently checks the bounded tree, full input binding, canonical relation, every permutation, every lower-bound vector, all complete affine matrix substitutions, all energy comparisons, invertibility and the explicit epsilon. It never calls the producer or affine solver. The codec is the existing `exact_center.encode_exact/decode_exact` rational tuple codec. Stored rationals are bounded by 16384 bits before certificate arithmetic. Construction and internal verification spend one shared bounded Budget (default 2M cooperative work / 30 seconds); public verification has its own requested budget. Exhaustion is UNKNOWN, domain violations UNSUPPORTED for construction and malformed certificates INVALID for verification. Work is cooperative, not a hard CPU-instruction or wall-clock interrupt guarantee.
