# 建模后续步骤的自动化要求

用户要求后续建模步骤都能自动执行。本项目新增的处理步骤应接入统一建模入口，而非只交付需手工挑帧、改路径、复制清单的临时脚本。

- 使用本次任务的显式输入、帧身份、模型与绑定，不依赖历史run路径或特定视频帧号。
- 在执行前冻结有界计算策略、资源与输出位置；不使用结果误差挑最好样本。
- 在正常运行、缺数据、歧义、资源停止、取消各路径均产生明确状态。数据不足可保留部分结果和孔洞，不以伪造匹配换取完整外形。
- 自动执行只包括已实现并验证的动作。未知物理尺度、不可确定的对应、缺失视角或相机标定，不能通过提高权限或无限重试消除。
- 新步骤需要默认入口接线测试、可失败的数值/身份测试及来源绑定；报告自动链接结果。独立CLI用于调试复核，不能成为正常运行所必需的人工步骤。
- 既有记录保留。诊断、条件性XYZ、原生模型点、表面、CAD实体和精度验收分别报告，不能互相替代。

当前接入内容见[AUTOMATIC_POINT_REVIEW.md](AUTOMATIC_POINT_REVIEW.md)。本轮新增原始前景锚点及径向相机条件诊断，在同一默认分支内执行，共享原180秒/2GiB预算，无额外模型加载或人工参数。
