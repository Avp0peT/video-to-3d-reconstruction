## 1. 协议

| 项 | 值 |
|---|---|
| 图像 | `square_3x`（12 点，边长 2，每边 3 个采样） |
| 标架 | 索引 `(0, 3, 5)` = $(0,0),\ (2,0),\ (2,4/3)$ |
| 标架条件数 | $\mathrm{cond}=3.370$（良态） |
| 主臂样本 | 1000 次随机可逆仿射变换 |
| 变换生成 | $A=R_2\,\mathrm{diag}(s_1,s_2)\,R_1$ + 有界剪切，$\mathrm{cond}(A)\le50$（奇异值钳制保证） |
| 平移范围 | $[-5,5]^2$ |
| 随机种子 | 20261001 |
| 验收标准 | $\max\|\Delta\alpha\|,\ \max\|\Delta\beta\|<10^{-9}$ |

标架**随图像一起变换**：计算 $T(X)$ 的内部坐标时使用 $(TA,TB,TC)$。
这是定理成立的形式（见 `../specs/affine_coordinates.md` §3）。

## 2. 结果

### 2.1 主臂

| 量 | 值 |
|---|---|
| 变换次数 | 1000 |
| 条件数（min / median / max） | $3.370$ / $4.356$ / $116.456$ |
| $\max\|\Delta\alpha\|$ | $\mathbf{2.243\times10^{-14}}$ |
| $\max\|\Delta\beta\|$ | $\mathbf{2.109\times10^{-14}}$ |
| $\mathrm{median}\,\|\Delta\alpha\|$ | $6.661\times10^{-16}$ |
| 理论界 $64\,\mathrm{cond}\,\varepsilon$ | $1.655\times10^{-12}$ |
| 余量（界 / 实测） | $73.8\times$ |
| **是否满足 $10^{-9}$** | **是**（余量 $4.5\times10^{4}$ 倍） |
| 是否真的在测量（worst > 0） | 是 |

### 2.2 对照：实测值不为零

`worst = 2.24e-14 > 0`，说明"变换后"的坐标确实被重新计算过，
不是把"变换前"的值直接复制过来。若此项为 $0$，主臂的通过毫无意义。

### 2.3 病态臂（同一实验，仅改标架）

使用等距变换（旋转 + 平移），因为等距不会额外恶化标架条件数，
从而把"精度结论"与"标架被拒绝"两件事分开。

| flatness | $\mathrm{cond}([B-A,C-A])$ | 实测 $\max\|\Delta\|$ | 报告界 | 满足 $10^{-9}$ | 在界内 |
|---|---|---|---|---|---|
| $10^{-2}$ | $2.000\times10^{2}$ | $1.710\times10^{-14}$ | $2.842\times10^{-12}$ | 是 | 是 |
| $10^{-4}$ | $2.000\times10^{4}$ | $1.567\times10^{-12}$ | $2.842\times10^{-10}$ | 是 | 是 |
| $10^{-6}$ | $2.000\times10^{6}$ | $1.738\times10^{-10}$ | $2.842\times10^{-8}$ | 是 | 是 |
| $10^{-8}$ | $2.000\times10^{8}$ | $1.351\times10^{-8}$ | $2.842\times10^{-6}$ | **否** | 是 |
| $5\times10^{-9}$ | $4.000\times10^{8}$ | $1.391\times10^{-8}$ | $5.684\times10^{-6}$ | **否** | 是 |

### 2.4 平移臂

预测律 $\max\|\Delta\alpha\|\approx \varepsilon\|t\|/\|B-A\|$（$\|B-A\|=2$）：

| $\|t\|$ | 预测 | 实测 | 实测/预测 |
|---|---|---|---|
| $1$ | $1.110\times10^{-16}$ | $1.110\times10^{-16}$ | 1.00 |
| $10^{3}$ | $1.110\times10^{-13}$ | $6.151\times10^{-14}$ | 0.55 |
| $10^{6}$ | $1.110\times10^{-10}$ | $6.306\times10^{-11}$ | 0.57 |

## 3. 对照与可证伪性

| 检查 | 目的 | 结果 |
|---|---|---|
| worst > 0（§2.2） | 防止"没在测量" | 通过 |
| 病态臂必须**超过** $10^{-9}$（§2.3） | 证明 $10^{-9}$ 阈值具有区分力，不是自证成立 | 通过（$1.35\times10^{-8}>10^{-9}$） |
| 逐行 $ \Delta\le 64\,\mathrm{cond}\,\varepsilon$ | 把"恰好低于阈值"变成"理解为什么低于" | 全部通过，worst ratio $<1$ |
| 25 次随机置乱后逐索引一致 | 顺序无关性 | 通过（`test_gate_phase2.py`） |

## 4. 含义

**能得出的结论**

1. README 第 6 节的验收标准成立：内部仿射坐标在**一切可逆仿射变换**下不变，
   实测误差 $2.2\times10^{-14}$，比要求低 4 个数量级。
2. 这个数字**不是**运气：它同时满足理论界 $\mathrm{cond}\cdot\varepsilon\cdot64$，
   且实测中位误差 $6.7\times10^{-16}$ 已接近机器精度。
3. Phase 2 的 Gate 条件满足，可以进入 Phase 3（工程阻塞解除）。

**不能得出的结论**

1. 不能说"$1e-9$ 在任何标架上成立"——§2.3 明确给出反例。
2. 不能说"这个结果与尺度无关"——§2.4 给出了依赖平移幅度的独立失效模式。
3. **不能**用它推断识别能力。本实验使用**已知对应关系**
   （第 $i$ 个变换后点 = 第 $i$ 个原点的像）；识别问题的对应未知，
   是另一个难度等级的问题（`../specs/recognition.md` §4.4）。
4. 不能推断教材的正式编码形式（未决问题 Q1 仍未解决）。

## 5. 边界

| 边界 | 阈值 | 后果 |
|---|---|---|
| 标架条件数 | $\mathrm{cond}\gtrsim10^{6}$ | $10^{-9}$ 不可达，库改为报告可达精度 |
| flatness | $<10^{-9}$（`COLLINEAR_TOL`） | 标架被拒绝并抛错 |
| 平移幅度 | $\varepsilon\|t\|>\|B-A\|$ | 图像结构塌缩，标架退化，抛错 |
| 单次测量 | — | 存在舍入恰好抵消的配置，必须用多配置最大值 |

详见 [`../theory/numerical_limits.md`](../theory/numerical_limits.md)。
