## 3. 控制组（本次实验最关键的一节）

`UNRELATED_CONTROL` 把该图像与一个**同基数的随机点集**比较。
凡是对仿射变换成立的性质，在此**必须**被破坏。

实测：**7 项全部 `violated`**。

为什么必须有这一节：前 8 行的共线性 / 平行性 / 仿射坐标永远是 P。
若测量代码有缺陷——例如关系集合恒为空、或逐点比较错误地使用了排序后的坐标——
这三行仍然会全 P，而且看起来完全正常。
控制组是唯一能让这种缺陷暴露的配置。同理，
`test_unrelated_images_break_every_relation` 是这一节的单元测试版本。

## 4. 见证（证明 `V` 不是舍入噪声）

| family | 性质 | 见证 | 幅度 |
|---|---|---|---|
| translation | 绝对坐标 | 点 #0 | $4.161$ |
| rotation | 绝对坐标 | 点 #9 | $0.991$ |
| reflection | 绝对坐标 | 点 #3 | $3.578$ |
| similarity | 绝对坐标 | 点 #6 | $5.274$ |
| similarity | 距离 | 距离对 $(0,6),(3,9),(0,7)$ | $4.243$ |
| scale_x2_y05 | 距离 | 距离对 $(6,9),(5,10),(4,11)$ | $2.000$ |

结论：所有 `V` 的幅度都在 $O(1)$ 量级（图像本身尺度为 2），
比任何容差（$10^{-9}$ 量级）高 9 个数量级。
不存在"因为浮点噪声被判 V"的情况；反过来，
所有 `P` 的幅度都在 $10^{-15}$ 量级（见 `results/.../summary.json` 中的 `deltas`）。

## 5. 无见证（`-`）在什么情况下出现

本次使用的 `square_3x` 在每一行都有见证，因此表中没有 `-`。
`-` 出现在例如**正七边形**上：

- 圆周上三点不可能共线（直线与圆最多交于两点）
  → 共线三元组集合为空 → 共线性行必须报 `-`，**不是** `P`。

对应的单元测试：`test_shape_without_collinear_triples_is_reported_vacuous_not_preserved`。

这不是吹毛求疵：如果把"空集合相等"当成"性质保持"，
则任何"共线性保持"的结论都可以在没有任何共线三元组的图像上被声称，
而这类图像（随机点集、正多边形）恰恰是最常见的。

## 6. 方法学：两类性质不能用同一种方式测量

| 类型 | 性质 | 测量对象 | 判据 |
|---|---|---|---|
| 连续量 | 绝对坐标、距离、角度、长度比例、仿射坐标 | 数值 | 最大偏差 vs 容差 |
| 关系 | 共线性、平行性 | **关系集合** | 集合对称差是否为空 |

对平行性若测量"线段夹角"，剪切下会得到"平行性不保持"——
与 README 表格矛盾，而且错的是测量方法：仿射变换不保持角度，但保持平行关系。
